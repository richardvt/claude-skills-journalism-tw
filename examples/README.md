# Examples

5 個真實使用範例,展示 Claude 載入 `journalism-core-tw` 後可產出的內容。

每個範例都是**乾淨環境**下使用者一段 prompt 之後 Claude 的實際輸出整理。可直接複製貼上實驗,或當作工作流模板。

| 範例 | 觸發的主要 skill | 適用情境 |
|---|---|---|
| [foia-request-tw.md](foia-request-tw.md) | `foia-requests-tw` | 寫政資法申請書 + 訴願主張 |
| [fact-check-line-message.md](fact-check-line-message.md) | `fact-check-workflow-tw` + `source-verification-tw` | 查證 LINE 流傳訊息並寫成查核報導 |
| [ai-writing-detox-before-after.md](ai-writing-detox-before-after.md) | `ai-writing-detox-tw` + `newsroom-style-tw` | AI 起草新聞稿改寫前/後對照 |
| [story-pitch-tw.md](story-pitch-tw.md) | `story-pitch-tw` | 自由記者投稿提案信 + 媒體選擇 + 合約注意 |
| [earthquake-breaking-news-sop.md](earthquake-breaking-news-sop.md) | `crisis-communications-tw` | 突發地震新聞處理 SOP |

---

## 怎麼使用這些範例

1. **作為工作流模板**:把對應 prompt 改成你自己的情境,直接貼到 Claude Code 跑
2. **作為效果預期**:看 Claude 在類似情境下會產出什麼,評估是否符合你的需要
3. **作為教學素材**:新聞系課程、編輯部訓練、媒體素養工作坊可直接引用
4. **作為品質基準**:若你的場景跑出來品質明顯較差,可能是 prompt 不夠精確、或 plugin 沒正確載入
