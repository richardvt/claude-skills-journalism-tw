# 自由記者投稿提案

**情境**:自由記者想 pitch「食藥署過去 3 年對某連鎖餐廳衛生稽查紀錄」之深度調查報導。

**觸發 skill**:`story-pitch-tw`(主)+ 主動串接 `foia-requests-tw`(政資法申請)、`interview-prep-tw`(線人聯繫)、`data-journalism-tw`(資料視覺化)

---

## 使用者 Prompt

```
我是自由記者,想 pitch 一個「台灣食藥署過去 3 年對某連鎖
餐廳的衛生稽查紀錄」深度調查報導。

請幫我:
(1) 評估這題目最適合 pitch 給哪 2-3 家台灣媒體(及為什麼)
(2) 寫一封 pitch 信給其中最適合的一家
(3) 估算合理稿費 + 採訪時間預算
(4) 簽合約時要注意什麼
```

---

## Claude 輸出概要

### (1) 推薦 3 家媒體(排序)

**首選:報導者(The Reporter)**
- **為何適合**:非營利屬性,**沒有餐飲業廣告壓力**(商周、天下、聯合都接餐飲集團廣告,可能在編輯階段施壓修剪);食安、消費者保護、公衛議題是其核心
- **規格契合**:8,000-15,000 字深度,3 年 × N 家分店稽查紀錄正好填滿
- **加分**:常與資料視覺化團隊合作
- **風險**:稿費保守(非營利);製作週期長,你要扛 3-4 個月現金流

**次選:鏡週刊**
- 長篇調查報導招牌、有調查組;讀者廣
- 可同時提案文字 + **鏡好聽 Podcast**
- **風險**:鏡集團商業壓力,若該連鎖是大客戶可能踩煞車

**第三:READr**
- **資料新聞為核心**,3 年稽查紀錄是現成素材
- **風險**:文字篇幅較短,深度敘事不是其強項

**組合策略**:獨家證據夠強 → 先 pitch 報導者談獨家;婉拒再轉鏡週刊;READr 可作為**資料視覺化合作夥伴**。

### (2) Pitch 信(寄給報導者)

```
主旨:[Pitch] X 連鎖餐廳 3 年稽查違規 N 次,食藥署為何沒動作
     — 12,000 字深度調查 — 預計 2026-09 交稿

報導者編輯部 您好:

我是 [姓名],自由記者,長期關注 [食安/消保],
過去發表過 [作品 1]、[作品 2] 等相關報導。

【題目】
透過政資法申請食藥署及六都衛生局 2023-2025 年對 X 連鎖餐廳
之稽查紀錄,還原該品牌全台 [N] 家分店之違規態樣、裁處落差、
與企業內部反應機制。

【Hook】
X 連鎖 3 年內被衛生局稽查 [N] 次、開罰 [N] 次,違規類型集中
在 [食材保存溫度/員工衛生/廚房環境],但同一分店重複違規最高
達 [N] 次仍持續營業;另比對六都裁處金額,同樣違規在台北最低
罰 3 萬、在高雄卻達 15 萬,地方裁量落差是制度漏洞還是個案因素?

【Why now】
- 2025 年 [近期食安事件] 之後,食藥署於 [日期] 宣布要強化
  連鎖體系稽查
- 立法院本會期正審議《食品安全衛生管理法》修正,涉連鎖總部
  之連帶責任
- 此題目可同時對應「制度監督」與「立法現場」兩個時點

【Stakes】
- 消費者:全台 X 連鎖每日服務 [N] 萬人次
- 基層稽查員:訪談 3-4 位現/前任地方衛生局稽查員,揭露人力
  不足、罰則過輕、業者法務反制等系統性困境
- 立法:連帶責任條款若通過,將改變連鎖總部之風險治理

【規格】
- 形式:深度調查報導 + 資料新聞(可與 READr 視覺團隊共製)
- 字數:10,000-12,000 字主稿 + 互動資料庫
- 採訪對象:前/現任稽查員 3-5 人、食藥署官員、連鎖總部、
  食安學者、消保團體、若可能含吹哨者
- 製作週期:政資法申請 6-8 週 + 採訪 6 週 + 寫稿 3 週 = 約 4 個月
- 預定交稿:2026-09-30
- 影像:分店實地拍攝、稽查現場(若取得授權)
- Podcast:可同時提案鏡好聽以外之合作

【我為何適合寫這個】
- 已完成初步資料測試申請,確認食藥署與 [某縣市] 衛生局願意
  提供去識別化稽查紀錄(附 PDF 為其回函)
- 已建立 [N] 位前任稽查員聯絡(其中 [N] 位同意具名)
- [其他相關背景]

【相關作品連結】
- [作品 1]
- [作品 2]

我可在本週任何時段電話/視訊討論進一步細節,
也願意先寄一份 3 頁採訪計畫供編輯部評估。

謝謝您的時間。

[姓名]
[手機 / Email / 作品集網址]
```

**Pitch 信關鍵點**:
- **不要把該連鎖餐廳名字寫在標題或第一段** — 若 pitch 信被轉發或外洩,等於提前曝光調查對象。內文以 X 代稱,等編輯回信簽 NDA 後再揭露
- **附上你已做的初步證據** — 政資法測試回函、聯絡到的稽查員(化名)— 降低編輯部執行風險評估
- **主動提資料合作** — READr/視覺團隊 — 讓編輯覺得不用從零調度

### (3) 採訪時程 + 稿費估算

**時程(4 個月)**:政資法申請 6-8 週(可並行其他工作)+ 資料清理 2-3 週 + 採訪 4-6 週 + 撰稿 3-4 週

**稿費**:

| 項目 | 估算(NT$) | 備註 |
|---|---|---|
| 主稿稿費 | 50,000-80,000 | 報導者 12,000 字深度,5-7 元/字 |
| 資料新聞加成 | +15,000-25,000 | 視覺化額外工時 |
| 採訪費用報銷 | +10,000-20,000 | 高鐵、住宿、文件影印 |
| 政資法申請費 | +2,000-5,000 | 工本費 |
| 訪錄轉錄 | +3,000-8,000 | 外包(或自用 Whisper) |
| **合計底線** | **80,000-130,000** |  |

**談判建議**:
- **不要接 50,000 元以下** — 工時太長
- 申請獎助金:卓越新聞獎調查報導獎、Pulitzer Center、Internews 食安/公衛專案
- 一稿多賣:報導者主稿 + 鏡好聽 Podcast 分潤(注意獨家條款)

### (4) 簽合約必看 8 點(調查報導特別版)

1. **著作權與獨家性條款** — 是「買斷」還是「首刊權」?資料庫是你的,不是媒體的
2. **法律保護** — 該媒體**法務是否事前審稿+對外答辯支援**?**若合約寫「文責自負」直接拒簽**
3. **撤稿條款** — 「非因事實錯誤之撤稿(企業施壓、廣告主抗議),媒體應付全額稿費並歸還版權」
4. **修改權底線** — 重大改寫(改變立場、刪除關鍵段落、改標題反向)應作者同意
5. **線人保密義務** — 「合約應載明媒體不得要求你揭露匿名來源身份」;司法搜索時應對程序
6. **付款時間 + 採訪費實報實銷** — 標準是「發稿後 30-60 日內」;**採訪費應預先撥款或月結**
7. **延後 / 中止條款** — kill fee(中止費)應寫明,通常為議定稿費的 30-50%
8. **公開資料與後續報導** — 你整理的稽查資料庫,合約後**能否開放給其他公民團體 / 學術使用**?
