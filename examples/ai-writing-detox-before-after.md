# AI 寫作味改寫前/後對照

**情境**:用 AI 起草的政府新聞稿,要改成台灣可發稿的乾淨新聞稿。

**觸發 skill**:`ai-writing-detox-tw`(主)+ `newsroom-style-tw`(編務校對)

---

## 範例 1:科技政府新聞

### 使用者 Prompt

```
請檢查這段是否有 AI 寫作味,逐句指出問題並改寫:

在這個 AI 技術日新月異的時代,本市致力於打造一個全方位的智慧
城市生態。我們不僅優化了既有的交通系統,更通過大數據與人工
智能的深度結合,賦能每一位市民。值得我們深思的是,這項計畫
不單是一次技術的革新,更是對市政治理能力的一次重要考驗。
換句話說,我們的目標是讓每一位用戶 —— 從學生到長者 —— 都
能享受到科技帶來的便利。讓我們拭目以待。
```

### Claude 抓出 17 處問題

| 病灶 | 對應 SKILL |
|---|---|
| 「在這個 AI 技術日新月異的時代」 | ai-detox §三套語家族 |
| 「致力於打造」(2 個套詞合一) | ai-detox §一三大套詞 |
| 「全方位」 | ai-detox §一濫用形容詞 |
| 「智慧城市生態」 | ai-detox §一濫用名詞 |
| 「不僅...更...」 | ai-detox §三套路結構 |
| 「優化」(政府場景) | ai-detox §一三大套詞 |
| 「通過」(透過意) | ai-detox §二大陸用語 / newsroom §三 |
| 「人工智能」 | newsroom §三人名譯名(改「**人工智慧**」) |
| 「賦能」 | ai-detox §三大套詞 |
| 「值得我們深思」(2 次) | ai-detox §三家族 |
| 「不單是...更是」 | ai-detox §三套路 |
| 「換句話說」 | ai-detox §三贅詞 |
| 「用戶」 | newsroom §三大陸用語(改「**使用者**」) |
| 全形破折號「——」濫用 | ai-detox §四 |
| 「讓我們拭目以待」 | ai-detox §六結尾禁忌 |
| 「我們」濫用 | ai-detox §五語氣 |
| 三段排比湊深度 | ai-detox §四 |

### Claude 改寫後

```
本市 2026 年 5 月起導入 AI 影像辨識協助交通管理。
預計新增 200 個監測點,涵蓋雙北 6 區。預計減少
通勤尖峰時段壅塞 15%。
```

**改寫對照**:200 字 AI 味 → **3 句具體事實**;保留可發稿訊息(地點、時間、規模、預期效果)。

## 範例 2:深度報導引言段

### 使用者 Prompt(假設記者貼了一段)

```
在這條看似平凡卻又充滿故事的街道上,每一位居民都有著
自己不為人知的人生軌跡。本篇報導,將帶您走進這些默默
奉獻的小人物,感受他們對這片土地深沉的愛。
```

### Claude 改寫後

```
林桂英在這條街賣麵 32 年。她的店,今年要拆。
```

**改寫對照**:深度報導 AI 味套詞(「不為人知」「默默奉獻」「深沉的愛」)→ **2 句具體事實**(姓名 + 行業 + 年資 + 衝突點)。

## 範例 3:政策評論

### 使用者 Prompt

```
這項政策不僅關乎全民的權益,更是對國家治理能力的一次
重要考驗。從多元的視角來看,我們應該以更開放、更包容、
更前瞻的態度,共同打造一個更美好的未來。
```

### Claude 改寫後

```
行政院 2026 年 5 月通過健保費調漲案,平均每月增加 80 元。
在野黨已表態反對。
```

**改寫對照**:政策套語(「不僅關乎...更是...」「更開放、更包容、更前瞻」三段排比、「共同打造美好未來」)→ **2 句具體事實**(機關 + 日期 + 政策 + 反應)。

## 範例 4:含「大陸用語滲透」的科技訪談

### 使用者 Prompt

```
我們致力於打造一個全方位的軟件生態,通過大數據與人工智能
的深度結合,賦能每一位用戶。我們的服務器部署在全球各個
區域,確保極致的用戶體驗。
```

### Claude 改寫後(統一為台灣用語)

```
我們做的就是一套軟體平台。把資料丟進去,AI 會分析給你。
伺服器在亞太五個城市,有事我們半小時內回應。
```

**改寫對照**:
- 「軟件」→ 軟體 / 「人工智能」→ 人工智慧 / 「賦能」→(具體動作)
- 「服務器」→ 伺服器 / 「用戶」→ 使用者 / 「全球各個區域」→ 亞太五個城市(具體化)
- 「致力於打造」→(刪)/ 「極致的用戶體驗」→(刪)/ 整段口語化

## 範例 5:災害新聞

### 使用者 Prompt

```
這場驚天動地的災難,猶如一道深深的傷痕,刻在了這片土地
與每一位倖存者的心上。在風雨中,我們看見了人性最堅韌、
最美好的一面。
```

### Claude 改寫後

```
6 月 12 日的豪雨在花蓮造成 12 人死亡、43 人受傷;
鐵路中斷 36 小時。
```

**改寫對照**:災害文學味(「驚天動地」「深深的傷痕」「人性最堅韌」)→ **2 句具體傷亡與影響**(對應 newsroom §九「不用驚爆/震撼」+ 突發新聞數字紀律)。

## 用了之後

- ✅ AI 起草的東西可以**直接送上發稿前審核**,不必再人工逐句去 AI 味
- ✅ **大陸用語**(視頻/網絡/軟件/賦能/打造)自動偵測替換
- ✅ **新聞文體禁忌**(驚爆/揭密/震撼)自動避免
- ✅ 改寫後**保留核心事實**,只去除廢話
- ✅ 編務細節(譯名、數字、職稱)自動套用台灣慣例
