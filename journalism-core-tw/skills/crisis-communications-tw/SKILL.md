# 台灣新聞危機應變工作流程

突發新聞**第一個小時決定報導品質**。本 skill 提供突發事件即時應變、快速查核、社群擴散應對的台灣場景 SOP。

---

## 何時使用

- 突發新聞發生(地震、火災、政治事件、食安)
- 災害現場即時報導
- 重大政治、外交事件(總統發言、立法院突發)
- 機構危機(企業違法、醫療失誤、公部門爭議)
- 假訊息瘋傳需快速澄清
- 建置編輯部突發新聞 SOP

## 二、突發新聞時間軸 SOP

### 第 0-15 分鐘:確認事件存在

```markdown
- [ ] 第一個訊息來源是誰?(政府機關 / 目擊者 / 社群)
- [ ] 至少 2 個獨立來源確認?
- [ ] 截圖原始來源(可能被刪)
- [ ] Wayback Machine 立即存檔
- [ ] 通知編輯台
```

### 第 15-60 分鐘:即時報導第一稿

```markdown
- [ ] 5W1H 確認(誰/何時/何處/何事/為何/如何)
- [ ] 死傷數字以**官方**為準(消防局、警局、衛福部)
- [ ] 不引用未經查證之社群截圖
- [ ] 第一稿短、事實先行、可後續更新
- [ ] 標題避免「驚爆」「震撼」(參考 ai-writing-detox-tw §六)
```

**第一稿模板**:

```
【XX 訊】XX 縣市 XX 鄉鎮 XX 日 XX 時 XX 分發生 XX 事件,
[消防局 / 警察局 / 衛福部 / 該機關] 表示,[截至發稿時]
[傷亡數字 / 主要事實]。

事件發生於 [具體地點]。[簡要過程或現場狀況]。

[相關機關]初步調查,[原因 / 後續處理]。

本報導將持續更新。
```

### 第 1-6 小時:深入採訪

- 致電求證(機關發言人、現場救護、目擊者)
- 派記者到現場(若可達且安全)
- 跨機關交叉(消防 vs 警方 vs 衛福部)
- 避免循環引用(其他媒體報導 ≠ 一手來源)
- 更新版本標註「**○○○○ 年 ○ 月 ○ 日 ○ 時 ○ 分 更新**」

### 第 6-24 小時:背景與脈絡

- 歷史脈絡(類似事件、歷年比較)
- 法規面(涉哪些法條、誰主管)
- 專家觀點(學者、實務工作者)
- 受害者 / 倖存者訪談(慎處理,參考 `interview-prep-tw` §九)
- 社群擴散追蹤(觸發 `social-media-intelligence-tw`)

### 第 24-72 小時:深度報導

- 責任歸屬(哪個機關 / 個人需究責)
- 政策建議(類似事件如何避免)
- 政府回應(部會 / 立委質詢)
- 送 source-verification-tw + fact-check-workflow-tw 二重查核
- 法律審查(若涉個案責任)

## 三、台灣特有應變重點

### 地震

- **中央氣象署**(cwa.gov.tw)是**唯一**官方來源
- 規模(ML / Mw)、震度、震央、深度 — 引述以氣象署為準
- **常見誤稱**:氣象局已於 2023 年 9 月改制為**中央氣象署**
- 餘震資訊以氣象署為準,**不要引述 PTT 鄉民「自己感受」**

### 颱風

- 路徑、暴風圈、強度 — 中央氣象署
- 停班停課 — **由各縣市政府公告**(非中央)
- 災情 — 中央災害應變中心
- 不可預測未來路徑,**標明「依目前氣象資料」**

### 食安

- 違規商品 — **食藥署**「食品藥物消費者知識服務網」
- 違規業者依《食安法》§84-1 主動公開
- 不要等業者主動聲明(常常拖)
- 引述應註明「依食藥署○月○日公告」

### 兩岸軍事

- 共機越線 / 共艦進入 — **國防部即時軍事動態**每日下午發布
- 不要引述境外不明來源(可能是中國心戰)
- 美國 7th Fleet 動態 — 美國國防部官網
- 引述「不具名國安官員」要特別謹慎,標明匿名理由

### 公衛 / 疫情

- 病例數、死亡數 — **CDC 疾管署**
- 疫苗效力、副作用 — **食藥署 / CDC**
- 中藥、保健食品宣稱治病 — 食藥署藥品許可證查詢(觸發 `fact-check-workflow-tw` §十.7 健康類)

### 災害現場記者安全

- 戴**安全帽**、護目鏡、口罩、反光背心
- **不擋救難動線**
- **不採訪正在救援之傷者**(等送上救護車後)
- **不在崩塌、地震餘震、化學洩漏區停留**
- **隨身應急包**:乾糧、水、行動電源、急救包

## 四、NCC 廣電法規範(廣電媒體相關)

> 平面、網路媒體部分要求類似,但 NCC 主要規範廣電。

### 主要規範

- **《廣播電視法》**、**《衛星廣播電視法》**、**《公共電視法》**
- **新聞自律**:依《廣電法》相關條文,新聞報導應公平、查證、平衡
- **錯誤報導**:處新台幣 20 萬至 200 萬元罰鍰;情節重大者得勒令停止節目
- **NCC 新聞自律諮詢會議**:對重大爭議報導出具意見

### 廣電媒體危機時特別注意

- **死傷畫面**:不得呈現過度血腥
- **災害現場連線**:避免使用未經查證之畫面
- **政治新聞平衡**:選舉期間特別嚴
- **兒少報導**:依《兒少法》§69 不得揭露身分

## 五、誤報與更正

> 突發新聞時誤報風險最高。**速報 + 速更正**比「等查證齊全」更符合新聞倫理。

### 即時更正 vs 全篇撤稿

| 情境 | 處理 |
|---|---|
| **數字錯誤**(傷亡、金額) | 立即更正,加「**○月○日○時更新:傷亡數字由○改為○**」 |
| **時間錯誤** | 立即更正 |
| **歸屬錯誤**(消息來源弄錯) | 立即更正,致電原來源致歉 |
| **整篇主張錯誤**(基本事實扭曲) | **撤稿**,改用新版重寫;原稿留存附「**已撤稿**」標記 |
| **照片誤用** | 立即下架,加標「**圖片誤植,已修正**」 |
| **被當事人質疑** | 評估證據,若有理據則更正;不直接屈服於壓力 |

### 更正聲明模板

```
[更正聲明]
更正日期:2026 年 5 月 28 日 ○時○分

本文於 2026 年 5 月 28 日 ○時○分原刊發,內容提及
「[原文不實之處]」,經查證後 [更正內容]。本社就此疏失,
向 [被影響之人 / 單位] 與讀者表達歉意。

正確內容應為:[更正後文字]
```

## 六、與 PR / 機構公關之分際

突發新聞時,機構公關常會:

| 公關動作 | 記者應對 |
|---|---|
| 「請等 ○ 點官方聲明」 | 等是合理的,但**告知讀者「目前等待官方回應」** |
| 「先別發,等明天記者會」 | **不接受**,新聞時效優先;若機構願給「獨家內幕」可協商但**仍可發目前已知** |
| 提供未經查證之「內部說法」 | 引述要明確標「機構公關表示」並交叉查證 |
| 要求「不要點名 ○ ○ ○」 | 評估公益必要性;若是責任歸屬之關鍵人物,**不接受隱匿** |
| 要求「全篇先給審稿」 | **拒絕**;部分引語回讀可協商 |

## 與其他 -tw skill 協作

`crisis-communications-tw` 處理**突發新聞之時序與壓力應變**。與其他 skill 緊密協作:

### 時間軸與工作流

```
[第 0-15 分鐘]  ← crisis-communications-tw  ← 你在這裡
       ↓
[第 15-60 分鐘]
   ├── source-verification-tw  快速驗證影像/帳號
   ├── fact-check-workflow-tw  即時查核
   └── newsroom-style-tw       第一稿格式
       ↓
[第 1-6 小時]
   ├── interview-prep-tw       快速訪當事人
   └── foia-requests-tw        申請機關完整資料(若需)
       ↓
[第 6-72 小時]
   ├── social-media-intelligence-tw  追蹤擴散與假訊息
   ├── fact-check-workflow-tw        深度查核
   ├── ai-writing-detox-tw           去 AI 味
   └── newsroom-style-tw             編務定稿
```

### 重疊處理

- **快速查核 vs 深度查核**:
  - `crisis-communications-tw`:5W1H 確認 + 2 個獨立來源
  - `fact-check-workflow-tw`:6 級評等 + 完整查核紀錄
  - **時間 < 1 小時用前者;> 1 小時轉後者**

- **災害現場社群截圖**:
  - `source-verification-tw`:單一截圖驗證
  - `social-media-intelligence-tw`:跨平台擴散追蹤
  - **單一截圖用前者;追蹤散布鏈用後者**
