# 台灣新聞事實查核工作流程

事實查核**是系統性流程,不是直覺判斷**。本 skill 提供主張驗證、證據文件化、評等決策的完整結構,並依台灣媒體生態與法律框架在地化。

---

## 何時使用

- 新聞稿發稿前的事實查核
- 撰寫專門查核報導(對主張評等)
- 採訪過程中驗證消息來源陳述
- 為新聞編輯部建立查核 SOP
- 訓練記者與編輯之查核標準
- 民眾轉傳訊息求證(LINE、Threads、PTT 看到後想驗證)

---

## 查核工作流程概覽

```
1. 主張提取  →  2. 主張研究  →  3. 證據蒐集  →
4. 聯絡來源  →  5. 評等決定  →  6. 文件化存檔  →  7. 發布或更正
```

每一步都應**留下書面紀錄**,以便:
- 編輯複查
- 對外爭議時可舉證
- 機構長期累積查核資料庫
- 訓練後進記者

## 一、台灣事實查核生態

### 台灣主要查核來源與 LINE 訊息查證合作來源

| 機構 | 性質 | IFCN/角色 | 特色 | 網址 |
|---|---|---|---|---|
| **台灣事實查核中心** (TFC) | 非營利專業查核機構 | IFCN 認證;狀態仍須查官網 | 與台灣媒體觀察教育基金會、優質新聞發展協會合作;報告深度長,常引用學者 | tfc-taiwan.org.tw |
| **MyGoPen** | 民間查核網站 | IFCN 認證;狀態仍須查官網 | 民眾轉傳「真的假的」訊息為主;反應快、文字較口語 | mygopen.com |
| **Cofacts 真的假的** | g0v 社群協作平台 | 社群協作平台,非單一 IFCN signatory | LINE bot 自動比對;開放社群編輯;**透明度高** | cofacts.tw |
| **蘭姆酒吐司** (Rumor & Truth) | 民間查核網站 | LINE 訊息查證合作來源;IFCN 狀態須逐案查證 | 健康、生活、詐騙類強項 | rumtoast.com |

> **不要把 LINE 合作來源等同於 IFCN 認證。** 引用「IFCN 認證」時,請以 ifcncodeofprinciples.poynter.org 當下公告為準;Cofacts 屬社群協作平台,適合做線索與交叉比對,不應被描述為單一 IFCN 認證機構。

### LINE 訊息查證(整合 4 機構)

民眾常用的「**LINE 訊息查證**」官方帳號(2019 上線):
- 加入官方帳號(LINE ID 搜尋「@linefactchecker」)
- 把可疑訊息**轉傳**至該帳號
- 系統自動比對 4 大查核機構資料庫
- 若已有查核結果,自動回覆;若無,由查核機構人工查證
- **記者實務**:報導前先查 LINE 訊息查證,確認此訊息是否已有現成查核可引用

### 行政院澄清專區

政府官方對假訊息的回應:
- 「行政院即時新聞澄清專區」(ey.gov.tw)
- 各部會官網「澄清新聞」「即時新聞回應」專區(例:衛福部、教育部、財政部)
- 中央選舉委員會「假訊息澄清專區」(選舉期間)

> **重要**:政府澄清專區是**單方資料**,代表政府立場。記者引用時應註明「依○○部澄清」並併陳其他立場。

### IFCN(國際事實查核聯盟)認證

**IFCN 五大原則**(查核機構簽署遵守):
1. **不偏不倚與公平性**
2. **來源透明**
3. **資金與組織透明**
4. **方法透明**(查核流程公開)
5. **公開且誠實的更正政策**

引用查核結果時:**IFCN 認證機構優先**;非 IFCN 機構(各部會澄清、PTT 鄉民查證、民間論壇)應視為**參考性資料**,不可直接當定論。

## 二、Step 1:主張提取

### 該查什麼

**應查 (事實性主張)**:
- 事實宣稱:「X 發生了」「Y 是真的」
- 統計數字(罹病率、補助金額、選票)
- 日期與時間軸
- 引語與歸屬(誰說了什麼)
- 因果主張:「X 導致 Y」

**不應查 (意見、預測、主觀)**:
- 「這項政策好/壞」
- 「我們應該做 X」
- 對未來的預測(「健保 2030 年會崩潰」)
- 品味或偏好(「這家拉麵最好吃」)

### 主張紀錄模板

```markdown
## 主張紀錄

**文章/來源**:[主張出現處]
**日期**:[何時]
**查核者**:[姓名]

### 主張 1
**陳述**:[精確引用或改述]
**陳述者**:[誰說的]
**脈絡**:[周邊背景]
**類別**:[統計/歷史/引語/因果]
**優先級**:[高/中/低,依對報導重要性]
**狀態**:[待查/已查證/不實/無法查證]
```

### 主張優先級

| 優先級 | 標準 |
|---|---|
| **高** | 對報導核心主張至關;查證簡單;若錯後果嚴重 |
| **中** | 支援細節;查證須時間 |
| **低** | 周邊細節;一般已接受;錯誤後果有限 |

**原則**:時間有限時,**先查高優先級**;時間充裕,**全部查**。

## 三、Step 2:主張研究(以台灣為主)

### 優先查一手資料(Primary source first)

| 主張類型 | 一手資料 (台灣) |
|---|---|
| 統計 | 主計總處、各部會統計處、原始研究報告 |
| 法律條文 | 全國法規資料庫 (law.moj.gov.tw) |
| 法院判決 | 司法院法學資料檢索系統 (judgment.judicial.gov.tw) |
| 政府公文、行政命令 | 行政院公報資訊網 (gazette.nat.gov.tw) |
| 立法院議案 | 立法院議事暨公報資訊網 (ppg.ly.gov.tw) |
| 監察院 | 監察院全球資訊網 (cy.gov.tw) — 糾正、彈劾、調查報告 |
| 審計部 | 審計部 (audit.gov.tw) — 中央、地方審計報告 |
| 政府採購 | 政府電子採購網 (web.pcc.gov.tw) |
| 政府開放資料 | data.gov.tw |
| 科學/醫學研究 | 國家衛生研究院、中央研究院、TAIR 同行評審期刊資料庫 |
| 醫療資訊 | 衛福部、CDC 疾管署、健保署、食藥署 |
| 環評資訊 | 環境部環評書件查詢系統 (eiadoc.moenv.gov.tw) |
| 教育資訊 | 教育部「教育部統計處」 |
| 企業財報 | 公開資訊觀測站 (mops.twse.com.tw) |
| 引語、發言 | 影音原檔、逐字稿、官方新聞稿、直接致電當事人 |

### 二手資料的評估(查核中常用,但需評估可信度)

若必須用二手資料:
- **離原始有多近**?(媒體報導 vs. 引述某媒體 vs. 引述「網友說」)
- **是否註明來源**?
- **多個獨立來源確認**?(獨立 = 互不引用對方)
- **有沒有相反報導**?

### 台灣主流媒體可信度參考(2026 年)

| 等級 | 媒體 |
|---|---|
| **高**(專業度與查核資源) | 中央社、報導者、READr、聯合報、自由時報 |
| **中**(主流但因議題立場有偏) | 中時、TVBS、東森、三立、民視、公視 |
| **較需查證** | 內容農場(KKnews、每日頭條)、特定立場部落格、Threads/PTT 文 |

> **記者實務**:即使「高」等級媒體報導,**仍應追到一手資料**;主流媒體報錯的案例不少(尤其是即時新聞、健康新聞、外電翻譯)。

### 研究文件模板

```markdown
## 對主張之研究:[主張簡述]

### 已查一手資料
| 來源 | 內容 | 確認/反駁 |
|---|---|---|
| [來源] | [發現] | [確認/反駁/部分] |

### 已查二手資料
| 來源 | 內容 | 可信度 |
|---|---|---|
| [來源] | [發現] | [高/中/低] |

### 證據缺口
- [查不到的部分]
- [仍需取得的資料]
```

## 四、Step 3:證據蒐集

### 證據種類與強度

| 證據類型 | 強度 | 備註 |
|---|---|---|
| 官方文件 | 強 | 法院判決、政府公文、機關報告 |
| 一手數據 | 強 | 原始資料集、自行分析 |
| 專家共識 | 強 | 多個獨立專家同意 |
| 具名來源 | 中 | 有姓名且直接知情之來源 |
| 同時期報導 | 中 | 事件發生當時之新聞報導 |
| 不具名來源 | 弱 | 用於指引採訪方向,**不可單獨作為證據** |
| 社群貼文 | 弱 | 可被刪除;脈絡至關重要;需截圖 + 存檔 |
| 維基百科 | 弱 | 可被任意編輯;**僅作為線索,不作證據** |

### 證據檢核清單

```markdown
## 證據蒐集:[主張]

### 文件證據
- [ ] 政府文件 / 公報
- [ ] 法院判決
- [ ] 公司財報 / 公開資訊觀測站
- [ ] 同行評審研究
- [ ] 官方聲明 / 新聞稿

### 人證
- [ ] 直接目擊者
- [ ] 領域專家
- [ ] 涉事各方(具名)
- [ ] 涉事各方(取得回應)

### 數據查證
- [ ] 取得原始資料集
- [ ] 檢視方法學
- [ ] 獨立重新計算
- [ ] 樣本量足夠

### 相反證據
- [ ] 已搜尋是否有衝突來源
- [ ] 衝突已記錄
- [ ] 矛盾已說明
```

### 存檔(這在台灣特別重要)

社群媒體與政治人物 Facebook、Threads 貼文容易被**刪文**(尤其引發爭議後),查核時務必:

| 工具 | 用途 |
|---|---|
| **Wayback Machine** (web.archive.org) | 網頁封存;立刻 archive 你查的網頁 |
| **Archive.today** (archive.ph) | 替代封存;不受機器人禁止 robots.txt 影響 |
| **本機截圖 + 時間戳記** | 加上瀏覽器網址列、系統時鐘截圖 |
| **下載 PDF** | 政府公文可下載 PDF 保存 |
| **國家圖書館** | 紙本檔案(舊新聞、地方報) |
| **離線備份** | 大量資料下載到外接硬碟 + 雲端兩份 |

## 五、Step 4:聯絡來源(求證程序)

### 答辯權

**一定要聯絡的對象**:
- 被查核之**人**或**機構**(主張陳述者)
- 提供**主張中具體事實**之來源
- 受**主張影響之第三方**(被點名者)

**做法**:
- **具體列出查核中之主張**(逐條)
- **給合理回應期限**(一般 24-48 小時;重大議題 72 小時;緊急即時新聞至少 6 小時)
- **書面文件化**(電子郵件、訊息截圖、官方信函)
- **記錄無回應**:時間與回應狀態都要記錄

### 求證信模板(台灣媒體常用格式)

```
受文者:○○○ 先生 / ○○部 公關室

主旨:○○媒體查核函

說明:
一、本人為○○媒體記者,正撰寫關於○○議題之查核報導/
    新聞,擬就下列主張向您查證:
    
    主張 1:「[精確引述]」
    出處:[出現處]
    
    主張 2:「[精確引述]」
    出處:[出現處]

二、請就上述主張惠予回應:
    - 確認/否認此主張
    - 提供支持證據之相關文件
    - 補充背景脈絡

三、回應期限:本媒體預訂於○○年○月○日(○)○時○分發稿,
    敬請於該時間前提供回應。逾時將以「未回應」處理。

四、回應方式:書面 (電子郵件 reporter@example.com) /
    電話 (02-XXXX-XXXX) /
    其他您方便之管道。

五、本人聯絡資訊:[姓名、職稱、媒體、電話、電子郵件]

謹此函達。

[記者姓名]
[日期]
```

### 文件化回應

```markdown
## 來源回應紀錄

### [來源姓名]
**聯絡**:[日期/時間、方式]
**期限給予**:[日期/時間]
**回應收到**:[日期/時間] / 未回應
**摘要**:[他們說了什麼]
**提供之證據**:[任何文件]
**可發布引語**:「[引語]」
**是否同意具名**:是 / 否(改稱「○○部官員」)
**是否同意公開**:是 / 否(對話僅供記者參考)
**書面/錄音留存**:[檔案位置]
```

## 六、Step 5:評等

### 內部用評等(編輯部 / 報告中)

**二元評等(簡單)**:
- ✅ **已查證** (Verified)
- ❌ **不實** (False)
- ⚠️ **無法查證** (Unverifiable)

### 對外發表用評等(查核報導用)

採用**台灣事實查核中心 / IFCN 通用 6 級制**:

| 評等 | 中文標籤 | 標準 |
|---|---|---|
| 1 | **正確** | 主張完整且精確,沒有重要遺漏 |
| 2 | **部分錯誤** | 主張部分為真,部分有誤、過時、誤導 |
| 3 | **事實釐清** | 主張有真實基礎,但缺乏關鍵脈絡而易誤解 |
| 4 | **錯誤** | 主張與證據相反 |
| 5 | **證據不足** | 證據不充分,無法確定真偽 |
| 6 | **未審查** | 因法律、隱私等原因不予查核 |

> **「Pants on fire / 火災式錯誤」**等情緒化標籤台灣較少用;改用「**錯誤**」搭配具體說明。

### 評等決策模板

```markdown
## 評等決定:[主張]

**主張**:[精確陳述]
**陳述者**:[誰]
**評等**:[評等]

### 支持主張之證據
- [證據 1]
- [證據 2]

### 反駁主張之證據
- [證據 1]
- [證據 2]

### 缺失之關鍵脈絡
- [脈絡 1]
- [脈絡 2]

### 來源回應
[聯絡時對方說的內容]

### 評等推理
[為何給這個評等而非其他評等]

### 信心度
[高 / 中 / 低,以及為什麼]
```

## 七、Step 6:文件化與存檔

### 查核檔案(每個主張一份)

```markdown
## 查核紀錄

**主張**:[精確陳述]
**出處**:[誰說、何處、何時]
**查核者**:[姓名]
**查核日期**:[日期]

### 驗證
**評等**:[評等]
**一手證據**:[列出含連結/位置]
**支持證據**:[列出]
**反駁證據**:[如有]

### 已聯絡來源
- [姓名]:[回應摘要]
- [姓名]:[截至 X 日無回應]

### 備註
[任何補充脈絡、保留意見、未來追蹤事項]

### 檔案
- [已存檔之文件、截圖、Wayback 連結]
```

### 證據存檔(台灣特殊重點)

涉及具體事實的截圖、影像、文件,務必:
- **多重備份**:Wayback Machine + Archive.today + 本機 + 雲端
- **時間戳記**:系統時鐘、瀏覽器網址列同時截圖
- **原始格式**:不要只貼到 Word;PDF、HTML、影像 metadata 保留
- **檔名規範**:`YYYY-MM-DD_主題_來源_序號.ext`
  - 例:`2026-05-28_NCC裁罰處分書_NCC官網_001.pdf`

## 八、Step 7:更正

### 何時更正

| 情況 | 處理 |
|---|---|
| 事實錯誤 | 立即更正,加更正說明 |
| 缺失脈絡 | 補充脈絡,通常不必正式更正 |
| 資訊已更新 | 更新,加「**更新日期**」 |
| 來源異議報導角度 | 評估主張,有理據時更正 |

### 更正聲明模板(台灣媒體慣用)

```
[更正聲明 / Correction]

更正日期:[日期]

本文原刊於 [日期] 之 [標題] 一文,文中提及「[原文]」,
經查證後 [更正內容描述]。本媒體就此疏失,謹向 [被影響
之人/單位] 與讀者表達歉意。

[更正內容詳述]

更新後完整段落:「[更正後文字]」
```

### 更正紀錄

```markdown
## 更正紀錄

**文章**:[標題 / 網址]
**原刊**:[日期]
**錯誤發現**:[日期]
**錯誤類別**:[事實 / 脈絡 / 歸屬 / 其他]

**原文**:
[已刊出之內容]

**更正後**:
[現有內容]

**發現方式**:
[讀者提示 / 內部複查 / 來源異議 / 等]

**更正發布**:[日期]
```

## 九、法律風險與妨害名譽(台灣)

### 《刑法》§310 誹謗罪

**條文要件**:
- 「**意圖散布於眾**,而**指摘或傳述足以毀損他人名譽之事**」
- 一般誹謗:1 年以下有期徒刑、拘役或新台幣 1 萬 5 千元以下罰金
- **加重誹謗**(散布文字、圖畫):**2 年以下**有期徒刑、拘役或新台幣 3 萬元以下罰金

**真實抗辯(§310 第 3 項)**:
- 對所誹謗之事能證明其為真實者,**不罰**
- **但**:涉及私德而與公共利益無關者,**仍不在保護範圍**

**實務上記者得免責之要件**:
1. **所言為真實**(有具體證據,非僅推測)
2. **與公共利益相關**(政治人物、公職、公司治理、公共議題)
3. **善意查證**(有合理查證程序,即使最終所言略有出入)

### 《刑法》§311 善意言論免責

對下列事項,於善意所發表之言論,雖屬誹謗,**不罰**:
- 因自衛、自辯或保護合法利益
- **公務員因職務而報告**
- 對於可受公評之事,而為適當之評論
- 對於中央及地方之會議,或法院或公眾集會之紀事,而為適當之載述

**新聞報導與評論**主要適用「對於可受公評之事而為適當之評論」(§311 第 3 款)。

### 《社會秩序維護法》§63 第 5 款

「**散佈謠言,足以影響公共之安寧者**」,處 3 日以下拘留或新台幣 3 萬元以下罰鍰。

**實務含義**:
- 比刑法 §310 更廣(不限於誹謗他人)
- **散布**即可成立(包含轉傳、分享)
- 「**足以影響公共安寧**」是要件 — 例:疫情、災害、戰爭相關不實訊息
- 一般由警察依職權處理;民眾可檢舉

### 其他相關法律

| 法律 | 條號 | 內容 |
|---|---|---|
| 《刑法》 | §309 | **公然侮辱** (非散布事實之純粹辱罵) |
| 《刑法》 | §151 | 恐嚇公眾 |
| 《刑法》 | §153 | 煽惑他人犯罪或違背法令 |
| 《傳染病防治法》 | §63 | 散布或傳播不實疫情消息 (3 年以下徒刑,300 萬元以下罰金) |
| 《證券交易法》 | §174 | 散布不實財報、影響股價 |
| 《選舉罷免法》 | §104 | 散布不實事項致候選人不當選 (5 年以下徒刑) |

### 記者查核時的法律保護策略

1. **完整保留查核紀錄**:書面、錄音、求證信、回應 — 證明已善意查證
2. **致電求證 + 文件化**:即使對方不回應也要記錄「曾於○月○日致電」
3. **報導時併陳被點名者立場**(即使他不願具名)
4. **避免「指摘私德」**:涉公共利益議題受 §310-III 保護;私德不受
5. **「言論」與「事實」分開**:評論可受 §311-III 保護;事實主張要有證據
6. **查核中遇到法律疑慮**:**諮詢法務或律師**,勿單憑「應該沒事」逕行刊登

## 十、常見台灣假訊息類別與處理建議

### 1. 政治、選舉假訊息

**特徵**:
- 選舉期間數量暴增
- 攻擊候選人或政黨
- 偽造黨內文件、發票影像
- 二度引述失真(從原報導擷取再改造)

**查核重點**:
- 中央選舉委員會(cec.gov.tw)有「候選人立場」官方資料
- 立法院質詢紀錄、政策投票紀錄
- 候選人正式登記資料

### 2. 兩岸假訊息

**特徵**:
- 多源於對岸社群(微博、抖音)經轉傳到 Threads / PTT / LINE
- 涉「武統」「中華民國滅亡論」「台灣經濟崩盤」等
- 也包括「中國經濟崩盤」「中共內鬥」等台灣本地散布

**查核重點**:
- 海基會、海協會、國台辦官方聲明
- 中央社駐外記者報導(較中性)
- 國際媒體(BBC、Reuters、AP)報導

### 3. 健康、疫情、疫苗假訊息

**特徵**:
- LINE 群組大量轉傳
- 「某中醫師說」「某醫學期刊」
- 訴求情緒(恐懼、絕望)

**查核重點**:
- 衛福部 CDC(疾病管制署)
- 食藥署
- 健保署
- 醫學期刊(PubMed、台灣醫學論文資料庫)
- 查核來源交叉比對(MyGoPen、蘭姆酒吐司等醫療/生活類常見來源;IFCN 狀態另查)

### 4. 食安、產品安全假訊息

**特徵**:
- 「致癌」「有毒」誇大標題
- 偽造食藥署文件

**查核重點**:
- 食藥署「食藥闢謠專區」
- 環境部、農業部
- 消基會

### 5. 詐騙、金融假訊息

**特徵**:
- 投資詐騙、假投資 LINE 群
- 偽造名人推薦(賴清德、郭台銘、Elon Musk 都被偽造過)

**查核重點**:
- 165 反詐騙專線(警政署)
- 警政署反詐專區
- 金管會、證期局
- 該名人本人 / 公司之澄清

### 6. 災害、急救假訊息

**特徵**:
- 颱風期、地震後大量出現
- 偽造氣象局資料、消防局指示

**查核重點**:
- 中央氣象署(cwa.gov.tw)
- 消防署
- 各縣市消防局

### 7. 移工、移民相關假訊息

**特徵**:
- 強化族群偏見
- 偽造犯罪統計

**查核重點**:
- 勞動部勞動力發展署
- 內政部移民署
- 警政署刑事局
- 國際勞工組織(ILO)

## 與其他 -tw skill 協作

`fact-check-workflow-tw` 處理**主張驗證的程序與紀律**。實務中是 5 個 -tw skill 共同支援新聞工作流的**前置查證階段**。

### 典型記者工作流順序(5 個 skill 串接)

```
[1. 資料蒐集]              ← foia-requests-tw
       ↓
[2. 來源驗證 / 內容查證]   ← source-verification-tw
       ↓
[2.5. 跨平台 OSINT]        ← social-media-intelligence-tw
       ↓
[3. 採訪準備 / 採訪]       ← interview-prep-tw
       ↓
[4. 主張驗證 / 查核]       ← fact-check-workflow-tw  ← 你在這裡
       ↓
[5. AI 起草草稿]
       ↓
[6. 去 AI 寫作味]          ← ai-writing-detox-tw
       ↓
[7. 編務校對]              ← newsroom-style-tw
       ↓
[8. 發稿]
```

### `fact-check-workflow-tw` 結束後,何時觸發其他 skill

| 場景 | 轉手 skill | 章節 |
|---|---|---|
| 查證所需資料無法在公開來源取得 | `foia-requests-tw` | 申請書範本與政資法 §10 應載 |
| 查核機關拒絕回應 / 拒絕公開 | `foia-requests-tw` | §18 限制公開 + 訴願管轄 |
| 主張涉影像/影片/AI 生成內容 | `source-verification-tw` | §三~§五內容查證、§六深偽真實案例 |
| 主張來自匿名帳號或可疑社群來源 | `source-verification-tw` | §二台灣社群平台帳號驗證 |
| 受訪者公開資料背景查證 | `source-verification-tw` | §十一訪談前公開資料 |
| 查證完進入撰稿階段 | 進入下一階段:`ai-writing-detox-tw` → `newsroom-style-tw` |
| 寫成查核報導,涉特定數字與引語 | `newsroom-style-tw` | §一數字寫法、§八引述動詞 |
| 寫成查核報導,涉政治敏感用語 | `newsroom-style-tw` | §十一兩岸關係用語、§十性別族群 |
| 查核結果涉妨害名譽風險 | (本 skill §九) + **諮詢法律** | — |

### 重疊處理(同問題多 skill 都有)

- **「政府機關官員姓名 / 職稱」**:
  - `fact-check-workflow-tw` §四:確認該官員是否確實如此發言、該職位現任者是誰
  - `newsroom-style-tw` §四:確認職稱書寫格式(第一次全名 + 職稱,後續姓 + 職稱)
  - **兩者搭配最完整**

- **「不具名來源」**:
  - `fact-check-workflow-tw` §四 + §五:**證據強度判斷** — 不具名來源不可單獨作為證據,需多重來源
  - `newsroom-style-tw` §八:**引述規範** — 具體標示匿名理由,不可用「據了解」
  - `foia-requests-tw`:法律層面(機關內部來源之保護)
  - **三 skill 搭配最完整**

- **「政府文件 / 機關回函」**:
  - `fact-check-workflow-tw` §三 + §四:評估證據強度
  - `newsroom-style-tw` §五書名號 + §六機構名稱:書寫格式
  - `foia-requests-tw`:若機關拒絕公開,申請或訴願

### 建議搭配安裝

`fact-check-workflow-tw` 可獨立用作「**查核工作流參考**」(也適用學術研究、政策評析)。**新聞工作者** **強烈建議同時安裝** `foia-requests-tw`、`ai-writing-detox-tw`、`newsroom-style-tw` — 4 個 skill 涵蓋從資料蒐集到發稿的完整工作流。
