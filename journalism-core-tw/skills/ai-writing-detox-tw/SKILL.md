# 中文 AI 寫作味去除 (台灣繁中專用)

好的寫作是隱形的。讀者注意到「文字風格」的瞬間,就是他從內容分心的瞬間。AI 中文寫作的 pattern 很明顯 — 一眼就能看出。在新聞工作中,這會直接侵蝕讀者信任。

> **本 skill 對應 upstream `ai-writing-detox` 的英文版**,但內容**完全替換為中文 (繁中/台灣) 的 AI 寫作 pattern**。英文版的「delve」「tapestry」「leverage」與中文無關,中文 AI 的 pattern 是另一套症狀庫。

## 何時使用

- 寫新聞稿、深度報導、評論、訪談稿、特寫
- 寫新聞稿前的編輯潤稿
- 寫社群貼文、電子報、Podcast 文稿
- 寫政策評析、白皮書、研究報告之新聞改寫
- **AI 協助起草任何中文內容後的人工檢查** (這是本 skill 最重要的用途)

## 寫作症狀總覽

中文 AI 味分為 **六層症狀**,從表面到深層:

| 層級 | 症狀 | 偵測難度 |
|---|---|---|
| 1. 詞彙 | 濫用單詞 (「優秀」「打造」「賦能」) | 易 |
| 2. 中國大陸用語 | 簡中翻譯型詞彙 (「視頻」「網絡」「信息」) | 中 |
| 3. 句型 | 套路結構 (「不僅...更...」「值得我們深思」) | 中 |
| 4. 結構 | 三段排比、過度條列、層級過深 | 難 |
| 5. 語氣 | 學者腔、演講腔、勵志腔 | 難 |
| 6. 新聞文體 | 浮誇標題、煽情敘事、設問引言 | 中 |

## 一、詞彙級症狀

### 濫用形容詞 (中文 AI 的「優秀病」)

| 詞 | 為何不該用 | 替代 |
|---|---|---|
| 優秀的 / 優異的 | 空洞讚美,等同英文 "excellent" 但更空 | 具體描述特點 |
| 精準的 / 精彩的 / 精美的 | 廢話形容詞 | 描述精準在哪、精彩在哪 |
| 卓越的 | 公關稿味 | 刪除或具體化 |
| 令人驚豔的 / 驚人的 | 讓讀者自己評判 | 描述事實本身 |
| 令人震撼的 / 震撼人心的 | 煽情 | 刪除 |
| 至關重要的 / 至關緊要 | AI 套語 | 重要 / (具體說明影響) |
| 不可或缺的 | 套語 | (具體說明依賴關係) |
| 不可忽視的 | 套語 | (具體說明) |
| 不容小覷的 | 套語 | (具體說明) |
| 引人深思的 | 替讀者下結論 | 刪除 |
| 富有意義的 / 有意義的 | 空洞 | (具體說明意義何在) |
| 深刻的 | 抽象 | (具體說明深在哪) |
| 全方位的 | 空洞 | 具體列出哪幾方面 |

### 濫用名詞

| 詞 | 問題 | 替代 |
|---|---|---|
| 生態 / 生態系 / 生態鏈 | AI 中文最氾濫的隱喻名詞 (對應英文 ecosystem);任何主題都可被湊一個「生態」 | 系統、產業、環境、市場、群落 (依語境;若不必比喻就直接寫「產業」) |
| 體系 (濫用時) | 大陸官方文體 | 制度、系統、架構 |
| 場景 (科技 PR 濫用) | 大陸科技業套詞 | 情境、使用情形、案例 (依語境) |
| 賽道 (商業 PR 濫用) | 大陸創投術語 | 領域、市場、方向 |
| 風口 | 大陸創投術語 | 趨勢、機會 |
| 痛點 | 大陸產品經理術語 (台灣也普及但氾濫) | (具體說明問題) |
| 閉環 | 大陸科技用語 | (具體說明流程) |

### 濫用動詞

| 詞 | 問題 | 替代 |
|---|---|---|
| 打造 | 中文 AI 第一名濫用詞;從 PR 稿擴散 | 興建、建立、開發、推動、設計、製作 — 依語境選 |
| 賦能 | 大陸科技業詞彙,台灣不常見 | (重寫具體動作) 例:「提升能力」「給予工具」 |
| 賦予 (使用過頻時) | 套語化 | (具體動詞) |
| 著力 / 致力於 | 大陸官方文體 | 在做、努力、投入 |
| 推進 | 大陸用語 (台灣多用「推動」「推行」) | 推動、推行、進行 |
| 助力 | 大陸用語 | 協助、幫助 |
| 賦予... | 過度使用時抽象 | (具體動作) |
| 落實 | 過度套用 | (具體執行什麼) |
| 強化 | 套詞 | (具體增強什麼) |
| 深化 | 套詞 | 加深、擴大 |
| 提升 (氾濫時) | 廣告詞 | (具體提升多少、提升什麼) |

### 濫用四字詞與成語

中文 AI 愛用四字詞「堆」起來,讀來像書面文宣:

| 套語 | 問題 |
|---|---|
| 日新月異 | AI 描述科技必出現 |
| 與時俱進 | AI 描述變革必出現 |
| 層出不窮 | AI 描述問題必出現 |
| 不勝枚舉 | AI 描述案例必出現 |
| 五花八門 | AI 描述多樣必出現 |
| 包羅萬象 | 公關詞 |
| 蔚為風潮 | 媒體稿套語 |
| 此起彼落 | 過度文藝 |
| 不容忽視 | (見上「不可忽視」) |
| 刻不容緩 | 過度急迫感 |
| 燃眉之急 | 過度修辭 |
| 蓬勃發展 | 公關詞 |
| 茁壯成長 | 公關詞 |
| 邁向新里程碑 | 慶賀稿套語 |
| 寫下新頁 | 慶賀稿套語 |
| 揚名國際 | 政府新聞稿套語 |
| 永續發展 (氾濫時) | 政策套語 (除非主題真為永續) |

> **原則**:四字成語**單次出現** OK;一篇 300 字內出現 3 個以上四字成語,大概率是 AI 味。

## 二、中國大陸用語滲透 (台灣記者必查)

許多 AI 模型 (含 ChatGPT、Claude、Gemini) 訓練資料中大陸簡中比例極高,輸出繁中時會殘留大陸用語。**這是台灣媒體與台灣讀者最容易識別的「AI 味」**。

### 「優化」「賦能」「打造」三大套詞

這三個詞特別點名,因為**在台灣媒體中已可見大陸用語滲透與 AI 寫作味疊加**:

- **優化**:台灣資工、產品、媒體都用,本身不算大陸味。但 AI 過度使用時讀來像產品 PR — 「我們**優化**了使用者體驗」可改「我們**改善**了使用者體驗」「我們**重新設計**了介面」
- **賦能**:翻譯自英文 enable / empower,中文世界中由中國大陸電商與管理學 (尤其阿里巴巴) 帶火。**台灣媒體與一般場景仍少用**,常被 AI 過度套用;改具體動作 (「給予 X 的能力」「協助 X」「培養 X」)。台灣相對中性的譯詞另有「**賦權**」「**培力**」「**授能**」
- **打造**:中文 AI 第一名濫用詞,**已普遍滲透台灣媒體**;**幾乎任何動詞都比「打造」更具體** (興建、推動、製作、設計、開發、籌備、舉辦)

> 「打造」「賦能」「優化」(產品 PR 場景時) 三個詞,在新聞稿、深度報導中**單篇出現一次就要警覺**,出現兩次以上即應改寫。

## 三、句型級症狀

### 「不僅...更...」家族 (中文 AI 第一名套路)

中文 AI 模型偏愛「不僅 X,更 Y」結構,因為簡單可生產、聽起來「有深度」。

```
AI:  這項政策不僅關乎全民權益,更是對國家治理能力的考驗。
人:  這項政策影響全民權益,也測試政府治理能力。
人:  這項政策關乎全民健保。

AI:  AI 不僅改變了我們的工作方式,更重塑了我們的思考模式。
人:  AI 改變了工作流程。它也在改變人們思考的方式。
```

同類套路:
- 「不只是...也是」
- 「不單是...更是」
- 「既...又...」(過度時)
- 「既有...又有...」
- 「一方面...另一方面...」(過度時)

**改寫原則**:把兩件事用句號隔開,各自寫清楚。中文 AI 用排比是為了**湊出深度**,實際上拆開常常發現兩半是廢話。

### 「值得我們...」家族

替讀者下結論的萬用句:

| AI 套語 | 處理 |
|---|---|
| 值得我們深思 | 刪除 (讓讀者自己思考) |
| 值得我們關注 | 刪除 |
| 值得我們深入思考 | 刪除 |
| 值得我們反思 | 刪除 |
| 不容我們忽視 | 刪除 |
| 需要我們共同努力 | 刪除 |
| 期待我們一起... | 刪除 |
| 我們應該... | (避免使用「我們」;改第三人稱具體主體) |

**新聞寫作原則**:記者**報導事實**,不替讀者下道德結論。「值得我們深思」是社論口吻,不是新聞口吻;即使在社論,具體論點比「值得深思」有效十倍。

### 「在這個...的時代」家族

時代感套語,常見於 AI 寫的引言段:

| AI 開頭 | 處理 |
|---|---|
| 在這個 AI 的時代 | 刪除整個分句;直接寫事實 |
| 在這個數位的時代 | 刪除 |
| 在這個快速變遷的時代 | 刪除 |
| 在這個資訊爆炸的世代 | 刪除 |
| 身處...的當下 | 刪除 |
| 面對...的現況 | 刪除 |
| 在這條...的道路上 | 刪除 |
| 隨著...的快速發展 | 刪除 (用具體時間點代替) |

**改寫原則**:具體時間 + 具體事件 取代抽象「時代」。「在這個 AI 的時代」改為「2025 年 OpenAI 發表 GPT-5 後」。

### 「並非偶然」「不容易」家族 (深度報導 AI 味)

深度報導與專題的 AI 標誌:

| AI 套語 | 為何有問題 |
|---|---|
| 這一切並非偶然 | 暗示存在「故事」卻不講事實 |
| 這條路並不容易 | 替主角下情緒結論 |
| 這背後有著不為人知的故事 | 廣告片金句 |
| 是 X 的縮影 | 過度抽象 |
| 是時代的見證 | 過度文藝 |
| 用生命寫下... | 過度修辭 |
| 在歲月的長河中... | 流水帳開頭 |

**改寫原則**:換成具體事實。「這條路並不容易」改為「他經歷了 3 次破產與 7 次搬遷」。

### 廢話開場詞

| 套語 | 處理 |
|---|---|
| 眾所周知 | 刪除 |
| 不可諱言 | 刪除 |
| 無庸置疑 | 刪除 |
| 毋庸置疑 | 刪除 |
| 顯而易見 | 刪除 |
| 值得一提的是 | 刪除 |
| 必須指出的是 | 刪除 |
| 重要的是 | 刪除 |
| 不難發現 | 刪除 |
| 我們可以看到 | 刪除 (除非真的在描述影像) |
| 由此可見 | 刪除 |
| 不可諱言 | 刪除 |

### 廢話結尾詞

| 套語 | 處理 |
|---|---|
| 總而言之 | 刪除 (除非真的需要總結) |
| 綜上所述 | 刪除 |
| 整體而言 | 刪除 |
| 總的來說 | 大陸味,刪除或改「整體來說」 |
| 簡而言之 | 刪除;若真要簡述,把簡述放在第一段 |
| 未來會如何發展,讓我們拭目以待 | 刪除 (極度 AI 味) |
| 未來仍有待觀察 | 刪除 (新聞特稿濫用) |
| 真正的考驗才剛開始 | 刪除 |
| 這個故事還沒有結束 | 刪除 |
| 在這條道路上,我們將持續關注 | 刪除 |

### 設問句濫用

中文 AI 用「設問」開場與承轉,試圖製造「對話感」:

```
AI 引言:
您是否曾想過,為什麼台灣的房價...?
為什麼?因為...
這意味著什麼?意味著...

人類引言:
台北市房價中位數已連 5 年高於月薪 30 倍。
```

**設問句適合演講與廣播,不適合書面新聞**。書面讀者不需要被「問」,直接告知就好。

### 「我可以理解嗎」「換句話說」家族 (AI 自言自語)

ChatGPT 中文輸出的個人標誌:

| AI 套語 | 處理 |
|---|---|
| 我可以這樣理解嗎? | 刪除 (這是 AI 模仿學生口氣) |
| 換句話說 | 慎用 (多數時候原句已表達清楚) |
| 也就是說 | 刪除 (95% 是贅詞) |
| 簡單來說 | 慎用 (若真要簡化,就重新寫一句) |
| 換言之 | 慎用 |
| 進一步而言 | 刪除 |
| 不僅如此 | 改用句點分隔兩件事 |

## 四、結構級症狀

### 三段排比 (Tricolon abuse)

中文 AI 與英文 AI 一樣愛「三段排比」,因為三段聽來「有節奏」:

```
AI:  這項計畫,需要更多的耐心、更深的對話、更具建設性的行動。
AI:  我們的目標是打造一個更公平、更透明、更具效率的社會。
AI:  這場改革,不僅關乎現在、更影響未來、更牽動下一代的命運。
```

**問題**:三項中通常只有一項是真實內容,其他兩項是「湊三」。

**改寫**:用一兩個具體論點,不要湊三。

```
人:  這項計畫需要 3 年與 80 億元預算。
人:  改革目標:每位民眾的健保自付額降至 15%。
```

### 過度條列

AI 偏好把所有內容都做成 bullet point,連散文都被切碎成條列:

```
AI 寫的政策分析:
台灣的健保制度面臨以下挑戰:
- 老化人口增加
- 醫療費用上漲
- 預算缺口擴大
- 醫護人力不足
- 民眾期待提高

我們應該:
- 強化財務管理
- 優化資源配置
- 提升醫療品質
- 確保永續發展
```

**問題**:看起來「結構清楚」,但實際上每個條目都是廢話。

**改寫**:用散文。需要列點時,列點要有**具體數據或事實**:

```
人:  健保制度三大挑戰:
     1. 65 歲以上人口佔 20%,2030 年將達 25%
     2. 預算缺口 2024 年達 776 億元
     3. 醫護人員過去 5 年離職率 18%
```

### 標題層級過深

AI 愛把一篇 1000 字的稿件切出 5 層標題:H1 → H2 → H3 → H4 → H5。新聞稿幾乎**只需要 H1 + H2**,深度報導**至多 H3**。超過就是 AI 模式套用論文格式。

### 全形破折號「——」濫用

中文 AI 在每段都用全形破折號「——」或「── 」表插入語,實際上中文常用句號、分號、頓號、括號就好。

```
AI 寫法:
台北市的房價 —— 比 5 年前高出 35% —— 已成為民怨主因。
2024 年的選舉 —— 國民兩黨激戰 —— 投票率仍然只有 58%。

中文標準寫法:
台北市的房價已成為民怨主因,比 5 年前高出 35%。
2024 年的選舉投票率只有 58%,即使國民兩黨激戰。
```

**原則**:中文裡破折號可用,但若每段都出現,就是 AI 模式。把破折號改成句號、逗號、括號。

### 過度的條列符號 (emoji、星號)

中文 AI 在條列前常加 emoji (✅⚠️🚀) 或星號 (★),這在公關稿與行銷文允許,**但不適合新聞**。

新聞稿用 1.、2.、3. 或一、二、三 即可。

## 五、語氣級症狀

### 「我們」的濫用

```
AI:  我們需要重新思考...
AI:  讓我們一起...
AI:  我們應該...
AI:  我們可以看到...
```

**新聞寫作原則**:
- 報導文字**不用「我們」** (除非引言內報導者刻意以本社/編輯部立場發言)
- 「我們」會把作者與讀者捆綁為「共同體」,這是社論或佈道的語氣,不是新聞
- 例外:**社論、編輯室手記、編輯臺**等明確署「本社/本報立場」之文體可用

### 過度禮貌的「您」

- **正式公文、學術論文**:用「您」
- **新聞稿、社群貼文、訪談稿**:用「你」
- **教學/說明性文字**:依語境,通常「你」較親近

AI 模型 (尤其 ChatGPT) 預設輸出常過度用「您」 ─ 在新聞文體中要全部改成「你」或乾脆刪掉。

### 學者腔 / 演講腔

| 套語 | 為何 AI 味 |
|---|---|
| 依我之見 | 假裝個人觀點 (新聞文體不該有「我」) |
| 在我看來 | 同上 |
| 私以為 | 假文言 |
| 從我的角度而言 | 同上 |
| 不揣淺見 | 假謙虛 |
| 容我冒昧地說 | 演講開場套語 |
| 由衷地希望 | 演講套語 |
| 殷切期盼 | 政府公報套語 |

### 自我提示式語句

AI 訓練自「教師對學生」的語料,輸出常見:

| 套語 | 處理 |
|---|---|
| 為了讓你更清楚理解... | 刪除 (直接寫清楚) |
| 為了方便理解,我們可以... | 刪除 |
| 接下來,我們將討論... | 刪除 (直接討論) |
| 在繼續之前,讓我們先了解... | 刪除 |
| 在進入主題之前... | 刪除 |
| 上述內容做個總結... | 刪除 |
| 我會以簡單的方式說明... | 刪除 |

## 六、新聞文體特有禁忌

### 標題禁忌詞

新聞標題本來就應避免下列詞,但 AI 偏愛 — 出現任何一個都該重擬標題:

| 禁用 | 為何 | 改寫方向 |
|---|---|---|
| 驚爆 / 驚傳 / 震驚 / 震撼 | 煽動 | 用動詞:「揭露」「指出」「確認」 |
| 揭密 / 揭祕 / 揭開 | 偽神秘 | (新聞本來就在揭露事實,不必標榜) |
| 不可思議 / 不可置信 | 替讀者反應 | (描述事實) |
| 真相曝光 / 驚人事實 | clickbait | (描述具體事實) |
| 內幕 | 標榜獨家但常為臆測 | 慎用,有實際內部來源才用 |
| 大爆料 | clickbait | 慎用 |
| 火爆 / 炸鍋 | 過度情緒 | 引發爭議、招致批評 |
| 神級 / 神操作 / 神回應 | 過度誇張 | (描述具體) |
| 翻車 / 翻船 | 網路 meme | (描述具體錯誤) |
| 殺出重圍 | 過度文藝 | 領先、超越 |
| 完美詮釋 / 完美演繹 | PR 詞 | (描述具體) |
| 震撼台日韓 / 引爆全網 | 誇大範圍 | 慎用,以實際擴散程度為準 |

### 引言段禁忌

**禁用引言開頭**:
- 設問句:「您是否曾想過...?」「為什麼台灣人...?」
- 時代套語:「在這個 AI 的時代」「在數位浪潮下」
- 文藝開頭:「在這條看似平凡的街道」「夜深人靜的此刻」
- 引用名人格言:「正如某某所言...」(除非該名言與報導主題密切相關)

**好的引言段**:**第一句就給最重要的事實**。

```
AI 引言:
在這個全民健保已經實施近 30 年的時代,
您是否曾想過,我們的健保到底面臨什麼挑戰?
這背後,有著一個鮮為人知的故事...

人類引言:
全民健保 2024 年虧損 776 億元,創歷年新高。
衛福部下週將提出費率調漲方案。
```

### 報導敘事禁忌

**形容詞濫用**:
- 「優秀的政策」「優異的成績」「卓越的領導」 ─ 新聞應**描述事實讓讀者判斷**,不替主角貼標籤
- 「驚人的數據」「驚人的成長」 ─ 數據本身會說話,「驚人」是替讀者下結論

**情緒化敘事**:
- 「令人不勝唏噓」「令人扼腕」「令人鼻酸」 ─ 過度替主角抒情
- 「淚灑現場」「哽咽落淚」 ─ 慎用,須當事人確實有此反應再寫,不要套詞
- 「在風雨中堅持」「在低谷中崛起」 ─ 文藝套詞

**過度比喻**:
- 「猶如...一般」「像是...的縮影」 ─ 若比喻不夠精確就刪掉

### 結尾禁忌

新聞稿尤其特稿、深度報導,**禁止下列結尾**:

| 禁用結尾 | 為何 |
|---|---|
| 值得我們深思 | AI 套詞 |
| 未來會如何發展,讓我們拭目以待 | AI 套詞 |
| 未來仍有待觀察 | 偽中立廢話 |
| 真正的考驗才剛開始 | 過度修辭 |
| 這個故事還沒有結束 | 連續劇結尾 |
| 在這條道路上,我們將持續關注 | 編輯臺套詞 |
| 期待...能夠... | 替讀者下心願 |
| 但願... | 同上 |

**好的新聞結尾**:**最後一個事實 + 後續關鍵時點**。

```
AI 結尾:
這場改革才剛開始,健保的未來會走向何方,
讓我們拭目以待,期待政府能拿出更具魄力的方案。

人類結尾:
衛福部下次健保費率審議會訂於 2026 年 7 月 15 日。
```

## 七、Before/After 範例

### 範例 1:科技新聞引言

**AI 味:**
> 在這個 AI 技術日新月異的時代,各家科技巨頭紛紛推出不僅功能強大、更兼具創新性的解決方案,值得我們深入思考的是,這場變革將如何重塑我們的未來。

**人類寫法:**
> OpenAI 5 月 12 日發表 GPT-5;Google 預定下月跟進。

### 範例 2:深度報導開頭

**AI 味:**
> 在這條看似平凡卻又充滿故事的街道上,每一位居民都有著自己不為人知的人生軌跡。本篇報導,將帶您走進這些默默奉獻的小人物,感受他們對這片土地深沉的愛。

**人類寫法:**
> 林桂英在這條街賣麵 32 年。她的店,今年要拆。

### 範例 3:政策評論

**AI 味:**
> 這項政策不僅關乎全民的權益,更是對國家治理能力的一次重要考驗。從多元的視角來看,我們應該以更開放、更包容、更前瞻的態度,共同打造一個更美好的未來。

**人類寫法:**
> 行政院 2026 年 5 月通過健保費調漲案,平均每月增加 80 元。在野黨已表態反對。

### 範例 4:訪談稿

**AI 味:**
> 「在我看來,這個議題其實沒有想像中那麼複雜,」王先生語重心長地說道,「我們需要的是更多的同理心、更深的對話,以及更具建設性的行動。」

**人類寫法:**
> 王志明說:「就是該修法。罰款太輕,我們公司每年寧可繳。」

### 範例 5:科技公司訪談

**AI 味 (中國大陸用語滲透):**
> 我們致力於打造一個全方位的軟件生態,通過大數據與人工智能的深度結合,賦能每一位用戶。我們的服務器部署在全球各個區域,確保極致的用戶體驗。

**人類寫法 (台灣繁中):**
> 我們做的就是一套軟體平台。把資料丟進去,AI 會分析給你。伺服器在亞太五個城市,有事我們半小時內回應。

### 範例 6:災害新聞

**AI 味:**
> 這場驚天動地的災難,猶如一道深深的傷痕,刻在了這片土地與每一位倖存者的心上。在風雨中,我們看見了人性最堅韌、最美好的一面。

**人類寫法:**
> 6 月 12 日的豪雨在花蓮造成 12 人死亡、43 人受傷;鐵路中斷 36 小時。

### 範例 7:商業新聞

**AI 味:**
> 在這個競爭激烈的市場環境中,該公司憑藉著卓越的技術實力、優異的服務品質,以及對客戶需求的深刻理解,成功打造了一個具有競爭力的領導品牌。

**人類寫法:**
> 該公司去年營收 47 億元,毛利率 38%,在台灣市佔率排名第一。

把寫好的稿子**逐句念出來**。聽起來像下列哪一種?

| 聽來像 | 處理 |
|---|---|
| TED 演講開場 | 重寫 |
| 政府公關稿 | 重寫 |
| 立委質詢稿 | 重寫 |
| 政策白皮書 | 重寫 |
| 心靈雞湯 | 大幅重寫 |
| 學者論文 | 改成新聞口語 |
| 廣告文案 | 重寫 |
| **跟同事/朋友轉述新聞** | 留下 |

**核心判準**:口語化但具體。不是「口語化的廢話」,是「**像對熟人講話那樣具體、不囉嗦**」。

## 九、發稿前自我檢查清單

搜尋自己的稿子是否出現下列「強烈 AI 味」訊號:

### 第一輪檢查 (詞彙)
1. 「值得我們深思」「值得我們關注」「值得深入思考」 → 刪
2. 「在這個...的時代」「身處...當下」 → 刪或具體化
3. 「打造」 → 換具體動詞
4. 「賦能」 → 改具體內容
5. 「優秀的」「優異的」「卓越的」 → 刪除空洞讚美或具體化
6. 「至關重要」「不可或缺」「不容忽視」 → 刪或具體說明
7. 「驚人的」「令人震撼」 → 刪除 (讓事實本身說話)

### 第二輪檢查 (大陸用語)
1. 「視頻」「網絡」「軟件」「信息」「賬號」「程序」(軟體意) 「服務器」「算法」 → 改台灣用語
2. 「打造」「賦能」「賦予」「落實」(過度時) → 改具體動詞
3. 「全方位」「一系列」「進一步」 → 慎用
4. 「優化」(產品 PR 場景時) → 改「改善」「重新設計」
5. 「直接」「通過」(透過意) → 改「透過」

### 第三輪檢查 (句型)
1. 「不僅...更...」「不只是...也是」 → 拆兩句
2. 「您是否曾想過...?」設問句開頭 → 改陳述句
3. 「換句話說」「也就是說」「進一步而言」 → 刪 (多為贅詞)
4. 「我們」(非社論場景) → 移除或改第三人稱
5. 「您」(新聞場景) → 改「你」或刪

### 第四輪檢查 (結構)
1. 同段內出現 3 個以上四字成語 → 削減至 1 個
2. 全形破折號「——」在 3 段以上連續出現 → 改逗號/句號/括號
3. 三段排比 (A、B 與 C) → 削減為一兩項具體論點
4. 標題層級超過 H3 → 重新組織
5. 條列項超過 7 個且無具體數字 → 改散文

### 第五輪檢查 (新聞文體)
1. 標題有「驚爆」「揭密」「震驚」 → 重擬
2. 引言段不是事實先行 → 重寫
3. 結尾是「值得深思」「拭目以待」「待觀察」 → 改具體事實
4. 過度形容詞 (「優異」「驚人」) 修飾事實 → 刪形容詞
5. 「猶如...」「彷彿...」比喻不精確 → 刪或具體化

**只要任何一條符合,稿子需要再過一輪**。

## 十、判斷自己寫的還是 AI 寫的測試

寫完一段後,問自己:

1. **這段話有具體事實嗎?** (人名、數據、地點、時間)
2. **形容詞有實際內容嗎?** (「優秀的」優秀在哪?)
3. **三段排比是真的有三件事,還是湊出來的?**
4. **設問句後面有真實回答,還是只有抒情?**
5. **結尾是不是「值得深思」「期待」「拭目以待」?**
6. **「我們」是社論立場,還是莫名其妙的「我們」?**
7. **有沒有「打造」「賦能」「視頻」「網絡」?**

**5 題以上回答「沒/沒/湊/抒情/是/莫名/有」→ 重 AI 味,要大改**

## 十一、終極測試

接受任何 AI 協助起草的中文文字之前,問:

1. **這個字/句刪掉會不會影響意思?** → 不會影響就刪
2. **同個意思,有更短的寫法嗎?** → 有就用短的
3. **我會這樣跟同事講話嗎?** → 不會就重寫
4. **這段是在增加資訊,還是在讓自己看起來厲害?** → 後者刪
5. **這段有沒有大陸用語?** → 有就改

## 十二、進階:中文 AI 結構標誌

除了單詞、句型、結構,中文 AI 還有幾個**段落級**標誌:

### 1. 「總分總」結構

AI 段落常呈現:
- 第 1 句:**結論** (「健保面臨重大挑戰」)
- 第 2-3 句:**論述** (排比「人口老化」「預算缺口」「人力不足」)
- 最後 1 句:**收束** (「這是我們共同的課題」)

新聞寫作不必每段「總分總」,有時候一段就是一個事實。

### 2. 過度承接詞

AI 在段與段之間愛用「然而」「不過」「另外」「此外」「再者」「值得一提的是」「需要指出的是」,讓文章看起來「邏輯嚴密」。實際上**多數承接詞可以刪除**,讓兩段直接並列。

### 3. 過度同義反覆

AI 為了「展現深度」會把同個意思用兩三種說法重複講:

```
AI:  這項政策非常重要,具有深遠意義,將影響未來。
人:  這項政策影響未來 30 年的健保。
```

### 4. 名詞化 (動詞變名詞)

AI 寫作偏好把動詞變名詞,讓文字「正式」起來:

| AI (名詞化) | 人 (動詞直接) |
|---|---|
| 對於本案,做出相關之回應 | 回應本案 |
| 進行了討論 | 討論了 |
| 進行採訪 | 採訪 |
| 開展了調查 | 調查了 |
| 進行落實 | 執行 / 推動 |
| 做出貢獻 | 貢獻 |

中文 AI 名詞化是大陸科技/官方文體的標誌。

## 與其他 -tw skill 協作

`ai-writing-detox-tw` 處理**中文寫作的 AI 味**(套語、結構、語氣)。當問題超出「AI 味」範圍進入「**編務規範**」或「**政府資料申請**」時,轉手給其他 -tw skill。

### 典型記者工作流順序

```
[1. 資料蒐集]              ← foia-requests-tw
       ↓
[2. 來源驗證 / 內容查證]   ← source-verification-tw
       ↓
[2.5. 跨平台 OSINT]        ← social-media-intelligence-tw
       ↓
[3. 採訪準備 / 採訪]       ← interview-prep-tw
       ↓
[4. 主張驗證 / 查核]       ← fact-check-workflow-tw
       ↓
[5. AI 起草草稿]
       ↓
[6. 去 AI 寫作味]          ← ai-writing-detox-tw  ← 你在這裡
       ↓
[7. 編務校對]              ← newsroom-style-tw
       ↓
[8. 發稿]
```

### `ai-writing-detox-tw` 抓出問題後,何時轉手

| 抓到的問題 | 轉手 skill | 章節 |
|---|---|---|
| 「據了解」「消息指出」等模糊不具名來源 | `newsroom-style-tw` + `fact-check-workflow-tw` | newsroom §八(匿名規則)+ fact-check §四、§五(證據強度評估) |
| 改寫後的文字含具體數據、引語、人名等事實主張 | `fact-check-workflow-tw` | §二主張提取、§五評等(寫完文字風格還要查證內容真偽) |
| 改寫後涉及社群截圖、影片、深偽案例引用 | `source-verification-tw` | §三反向圖搜、§五 AI 偵測、§十二法律風險(《選罷法》§104) |
| 大陸用語對照的細節(視頻 vs 視訊 vs 影片) | `newsroom-style-tw` | §三人名譯名、§十一兩岸關係用語 |
| 改寫成品涉及法律名稱、書名、報名 | `newsroom-style-tw` | §五書名號《》與篇名號〈〉 |
| 改寫成品涉及政府機關名稱 | `newsroom-style-tw` | §六機構名稱(簡稱規則) |
| 改寫成品涉及人名 + 職稱 | `newsroom-style-tw` | §三人名譯名、§四職稱頭銜 |
| 數字寫法(阿拉伯 vs 中文) | `newsroom-style-tw` | §一數字寫法 |
| 標點符號正確性 | `newsroom-style-tw` | §五引號與標點符號 |
| 報導涉政府資料申請 | `foia-requests-tw` | 申請書範本與政資法 §18 |

### 重疊處理(同問題兩 skill 都會抓)

- **大陸用語滲透**:
  - `ai-writing-detox-tw` §二:從「**AI 寫作味**」角度抓(視頻/網絡/軟件/賦能/打造)
  - `newsroom-style-tw` §三 人名譯名(川普/特朗普)+ §十一 兩岸用語 + 散見於其他章節
  - **兩個都會抓,等於雙重保險**;角度互補(前者抓一般用語,後者抓人名地名與政治用語)

- **新聞文體禁忌詞**(驚爆/揭密/震撼):
  - `ai-writing-detox-tw` §六 詳細列舉 + 解釋為何不用
  - `newsroom-style-tw` §九.標題寫作 簡要重申
  - 標題擬定時兩者搭配最完整

- **「我們」「您」濫用**:
  - `ai-writing-detox-tw` §五 語氣級症狀 — 普遍性禁止
  - `newsroom-style-tw` §九.標題寫作 不另列(假設前 skill 已處理)
  - **以 `ai-writing-detox-tw` 為準**

### 建議搭配安裝

只裝 `ai-writing-detox-tw` 可獨立用作「中文寫作體檢工具」(廣告文案、自媒體、學術寫作皆可)。**新聞工作者**建議同時安裝 `newsroom-style-tw`(編務規範)與 `foia-requests-tw`(資料申請)。

## 附錄:常見「半 AI 味」詞 — 不是禁用,但慎用

下列詞**不一定 AI 味**,但 AI 與 PR 稿過度使用,需依語境判斷:

| 詞 | 為何半 AI 味 | 何時可用 |
|---|---|---|
| 創新 | PR 詞氾濫 | 主題真為創新時 |
| 突破 | 過度誇張 | 確實是突破 (有具體比較基準) 時 |
| 引領 | 公關詞 | 確實領先且有依據時 |
| 重塑 | 過度修辭 | 確實是結構性改變時 |
| 願景 | 政策套語 | 政策文件主題即「願景」時 |
| 賦予 | (見上「賦能」) | 法律語境 (「賦予權利」) OK |
| 推進 | 大陸味 | 軍事/工程語境 OK,一般改「推動」 |
| 全力 (打造/支持/推動) | PR 套詞 | 慎用 |
| 攜手 (打造/合作) | PR 詞 | 慎用 |
| 共創 | PR 詞 | 政策合作場景慎用 |
| 共享 | PR 詞 (除非真的共享) | 「共享經濟」場景 OK |
| 邁向 | 政策套詞 | 慎用 |
| 開創 | PR 詞 | 確實是開創性場景 OK |
| 共同 (氾濫時) | 套詞 | 慎用 |

## 寫好之後

如果你讀者讀完一段文章,腦中浮現「**這篇 AI 寫的吧**」這個念頭 — 即使你已經把所有事實核對得很精確、引述都正確 — **你已經失去他的信任**。

文字風格是新聞工作的**信任介面**。AI 寫作味讓讀者懷疑:「事實也是 AI 編的吧?」即使你的事實沒有錯,讀者已經先打了折扣。

**好的中文寫作是隱形的**。讀者讀完只記得「啊原來健保虧了 776 億」,不會記得「文字好像很有 AI 味」。
