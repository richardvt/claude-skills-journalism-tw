# 台灣媒體投稿與題目提案工作流程

寫稿前先 pitch,**比寫完再投有效十倍**。本 skill 提供台灣媒體之投稿格式與題目提案模板。

---

## 何時使用

- 向特定媒體 pitch 一則題目
- 申請成為某媒體之特約記者 / 撰稿人
- 投稿評論、社論、專欄
- 提案深度報導(調查、特寫)
- 寫競標式 pitch(對應贊助計畫、獎金)
- 內部編輯部 pitch 會議

---

## 一、Pitch 結構(Why 比 What 重要)

### 經典 4 段結構

```markdown
## 1. Hook (鉤子,1-2 句)
[最有衝擊之事實 / 矛盾 / 故事點]

## 2. Why now (時效性,1-2 句)
[為何此刻發稿;搭配時點、政策、事件]

## 3. Stakes (議題與利害關係人,2-3 句)
[誰受影響、影響有多大、為何讀者該關心]

## 4. Format (規格,1-2 句)
[預估字數、形式、是否含資料/圖表/影像、預計交稿日]
```

### 常見錯誤(pitch 失敗原因)

| 錯誤 | 改進 |
|---|---|
| 「我想寫關於 X」 | 「X 上週發生 Y,導致 Z,但無人報導」 |
| 沒 why now | 加時效鉤子 |
| 全是抽象主題 | 加一個具體故事或人物 |
| 沒明確格式 | 字數、形式、交稿日要清楚 |
| 沒讀過該媒體既有作品 | 引述媒體曾刊過之相關文章 |

## 二、台灣主要媒體投稿格式

### 投稿資訊更新規則

媒體投稿窗口、稿費、子品牌與編輯人員變動很快。推薦任何媒體前先查該媒體最新的「投稿 / 聯絡我們 / 徵稿 / About」頁;若未查證,輸出時要明確標示「未即時確認」。

- 區分**已確認投稿窗口**與**推測適合投稿對象**。
- 不承諾稿費;只用行情範圍與「需向編輯確認」。
- 不建議先寫完整稿再海投;先寄短 pitch 或詢問是否收外稿。
- 若使用外部頁面,在建議中記錄 `last_checked` 日期。

```markdown
## 媒體選擇輸出格式

- 推薦媒體:
- 契合理由:
- Why now:
- 投稿窗口狀態:已確認 / 未即時確認
- 稿費假設:
- 風險:
- 下一步:
```

### 報導者(The Reporter)— 非營利、深度為主

- **網址**:twreporter.org
- **聯絡**:每組記者有公開聯絡;投稿可寄總編輯部
- **強項**:長篇調查、人物特寫、社會議題
- **字數**:8,000-15,000 字深度報導為常見;短稿 2,000-5,000 字
- **稿費**:有(雖然非營利但會付外部投稿者)
- **特性**:重視第一手採訪、影像視覺,**較長製作期**

**Pitch 重點**:
- 強調**社會議題的長期影響**
- 提出**具體採訪計畫**(誰、什麼、何時)
- 預估**製作週期**(深度報導 1-3 個月正常)

### 天下雜誌 / 天下獨立評論

- **網址**:cw.com.tw
- **強項**:財經、政策、商業
- **字數**:2,000-5,000 字評論;5,000-10,000 字深度
- **稿費**:有
- **特性**:**讀者偏菁英、決策者**;**圖表視覺化要求高**

**Pitch 重點**:
- 強調**對企業 / 政策決策者之啟發**
- 數據要扎實
- 國際比較常加分

### 商業周刊

- **網址**:businessweekly.com.tw
- **強項**:企業案例、產業分析、人物
- **字數**:3,000-8,000 字
- **稿費**:有
- **特性**:讀者**經理人**為主;偏成功學

**Pitch 重點**:
- 強調**商業洞察**
- 案例為主(非理論)
- 故事性強

### READr

- **網址**:readr.tw
- **強項**:資料新聞、互動敘事
- **字數**:不定(影像 / 互動為主)
- **稿費**:有(部分專案制)
- **特性**:**資料 + 視覺**;適合資料記者投稿

**Pitch 重點**:
- 提供**資料來源**
- 解釋**互動形式**(圖表、地圖、時間軸)
- 與**主視覺團隊**合作

### 鏡週刊 / 鏡新聞 / 鏡好聽

- **網址**:mirrormedia.mg
- **強項**:政治、社會、人物、調查;**Podcast 影視**
- **字數**:8,000-15,000 字深度;短稿 2,000 字
- **稿費**:有
- **特性**:**長篇調查報導**為招牌;**鏡好聽** Podcast 為延伸

**Pitch 重點**:
- 調查報導要有**獨家證據**
- 人物特寫要有**戲劇張力**
- 可同時提案**文字 + Podcast**形式

### 聯合報、聯合新聞網

- **網址**:udn.com
- **強項**:綜合大報、深度副刊
- **字數**:評論 800-1,500 字;深度 3,000-6,000 字
- **稿費**:有
- **特性**:**讀者廣**;政治立場偏中(部分泛藍)

**Pitch 重點**:
- 言論版有**「鳴人堂」「轉角國際」「願景工程」**多個子品牌
- 各品牌風格不同,**先研究目標**

### 自由時報

- **網址**:ltn.com.tw
- **強項**:綜合大報
- **政治立場**:偏綠
- **字數**:評論 800-1,500 字

### 中國時報 / 中時新聞網

- **網址**:chinatimes.com
- **政治立場**:偏藍
- **字數**:評論 800-1,500 字

### INSIDE 硬塞的網路趨勢觀察

- **網址**:inside.com.tw
- **強項**:科技、新創、互聯網
- **字數**:1,500-3,000 字
- **稿費**:有
- **特性**:讀者**科技工作者、創業者**

**Pitch 重點**:
- 強調**科技趨勢**或**新創案例**
- 第一手採訪比編譯外電更受歡迎

### TechOrange 科技報橘

- **網址**:techorange.com
- **強項**:科技、AI、職場
- **特性**:讀者**白領科技業**

### 關鍵評論網 (The News Lens)

- **網址**:thenewslens.com
- **強項**:綜合議題、評論
- **字數**:1,000-3,000 字
- **稿費**:有(部分 free)
- **特性**:讀者**年輕族群、學生**;**允許各種立場**

**Pitch 重點**:
- 接受**個人觀點 + 事實基礎**之評論
- 議題不限,但要有**新角度**

### Womany 女人迷

- **網址**:womany.net
- **強項**:女性議題、性別、職場
- **字數**:1,500-3,000 字
- **特性**:讀者**年輕女性、性別議題關心者**

### 報橘、INSIDE、TO 為同一集團(Buzz Orange)

### 公視 / PNN / 公視新聞網

- **網址**:news.pts.org.tw
- **強項**:公廣集團、紀錄片
- **字數**:深度報導
- **特性**:**獨立性高、預算有限**

### 中央社

- **網址**:cna.com.tw
- **強項**:即時新聞、國際、台灣對外發稿
- **特性**:**官方通訊社**;**較少接受外部 pitch**(內部記者為主)

### 端傳媒(港版,台灣讀者亦多)

- **網址**:theinitium.com
- **強項**:港台中議題、深度評論
- **字數**:3,000-8,000 字
- **特性**:讀者**港台中華語圈**;**繁中為主**

### 自媒體 / 個人 Substack 投稿

- 個別自媒體可投稿(例如某些政治評論者、產業分析師)
- **稿費**:多無;曝光交換
- **Pitch 重點**:與該自媒體既有讀者契合

## 三、Pitch 模板(電子郵件)

### 模板一:單篇題目 pitch

```
主旨:[Pitch] [一句話標題] — [字數預估] — [預定交稿日]

[編輯名] 您好:

我是 [姓名],[簡短自介,1 句]。

【題目】
[一句話描述題目]

【Hook】
[1-2 句最有衝擊之事實或矛盾]

【Why now】
[為何此刻]

【Stakes】
[2-3 句利害關係、誰受影響、為何讀者該關心]

【規格】
- 形式:[深度報導 / 評論 / 人物特寫]
- 字數:[預估]
- 交稿日:[預估]
- 含資料 / 圖表 / 採訪 / 影像:[列出]
- 是否搭配 podcast / 影片:[若有]

【我為何適合寫這個】
[1-2 句:背景、經驗、關係 / 一手資料]

【相關作品連結(若有)】
- [連結 1]
- [連結 2]

期待您的回覆。
[姓名]
[聯絡方式]
```

### 模板二:特約 / 長期合作 pitch

```
主旨:[特約合作提案] [姓名] — [主題領域]

[編輯主管] 您好:

我是 [姓名],[簡短自介]。我長期關注 [主題],
過去 [N] 年發表過 [數量] 篇相關報導 / 評論。

我想提案成為貴媒體 [短期 / 長期 / 月專欄 / 季專欄]
特約撰稿人,初步構想如下:

【主題定位】
[我可以持續產出之主題,範圍與深度]

【未來 3-6 個月之題目構想】
1. [題目 1] - [簡述]
2. [題目 2] - [簡述]
3. [題目 3] - [簡述]
4. [題目 4] - [簡述]

【產出頻率】
[每月 X 篇、每季 X 篇、不定期]

【稿費期望】
[字數 × 元 / 字] 或 [篇 × 元]

【我的作品集】
[作品連結,挑 3-5 篇最具代表性]

期待有機會討論。
[姓名]
[聯絡方式]
```

### 模板三:評論投稿

```
主旨:[投稿] [評論標題] — [字數]

[編輯] 您好:

我是 [姓名],[1 句自介]。隨信附上一篇 [字數] 字評論
〈[標題]〉,主題為 [一句話],切入角度為 [一句話]。

評論已 attach。

【為何適合貴媒體】
[1 句]

【我的相關背景】
[1 句]

若不適合,請告知,我會投至其他媒體。

[姓名]
[聯絡方式]
```

## 四、稿費與報價(2026 台灣行情)

以下為自由投稿與專案報導的粗略行情,不是保證價格。實際金額取決於媒體預算、採訪成本、授權範圍、是否含攝影 / 資料 / 影音、是否獨家與付款條件;稿費不明時,先向編輯確認再投入完整採訪與寫作。

| 形式 | 稿費範圍 (NT$) |
|---|---|
| 短評(800-1,500 字)| 1,500-5,000 |
| 一般評論(1,500-3,000 字)| 3,000-10,000 |
| 中篇報導(3,000-5,000 字)| 5,000-15,000 |
| 深度報導(5,000-10,000 字)| 15,000-40,000 |
| 調查報導 (10,000+ 字)| 40,000-150,000(視專案) |
| 影音搭配 / 互動 | 加成 30-100% |
| Podcast 配音 | 另計 |

**注意**:
- 台灣稿費**普遍偏低**(相對於採訪成本)
- **獎助計畫**(專題報導獎、卓越新聞獎、調查報導獎)可申請補助;報導者、英國《衛報》Open Society、Internews 等有國際獎助
- 公益議題可評估 **Internews**、**Pulitzer Center on Crisis Reporting** 等國際獎助;申請資格與題材每年變動,送件前查官方規範

## 五、自由工作者 vs 特約

| 項目 | 自由工作者 (Freelance) | 特約 (Contract) |
|---|---|---|
| 關係 | 案件式 | 長期合作 |
| 稿費 | 每篇 | 月 / 季固定 + 篇數彈性 |
| 編輯指派 | 通常自己提案 | 編輯 + 自己混合 |
| 福利 | 無 | 有時有(健保、勞保) |
| 智財 | 多保留(可轉載) | 看合約 |
| 採訪資源 | 自費居多 | 部分由媒體支付 |

### 合約須注意

- **著作權歸屬**(誰擁有完整版權)
- **獨家性**(同題目可否再投他刊)
- **修改權**(編輯改稿之底線)
- **撤稿賠償**(若編輯部撤稿後續)
- **付款時間**(發稿後 X 天)
- **保密 / 不競爭條款**

## 六、與其他 -tw skill 協作

```
[Pitch 階段]               ← story-pitch-tw (你在這裡)
       ↓ pitch 通過,開始採訪
[資料蒐集]                 ← foia-requests-tw
       ↓
[來源 / 內容驗證]          ← source-verification-tw
       ↓
[跨平台 OSINT]             ← social-media-intelligence-tw
       ↓
[採訪]                     ← interview-prep-tw + interview-transcription-tw
       ↓
[查核]                     ← fact-check-workflow-tw
       ↓
[撰稿]
   ├── ai-writing-detox-tw    去 AI 味
   └── newsroom-style-tw      編務(該媒體用字典範)
       ↓
[發稿]
```

### 重疊處理

- **媒體選擇**:
  - `story-pitch-tw`:評估**該媒體之風格、讀者、稿費**
  - `newsroom-style-tw`:該媒體之**編務規範差異**(用字、兩岸用語立場)
  - **Pitch 前看 story-pitch-tw;寫稿時依該媒體之用字規範**

- **特殊受訪對象**:
  - `story-pitch-tw`:特殊主題(性平、移工)可能需要**特定媒體**(女人迷、報導者)
  - `interview-prep-tw` §九:採訪該對象之**準則**
  - **媒體選擇用前者,採訪準則用後者**
