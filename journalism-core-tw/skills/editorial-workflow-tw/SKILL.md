# 台灣編輯部新聞流程

編輯部**生產力來自流程,不是英雄**。本 skill 提供選題、稿單、排期、審核之台灣場景模板。

---

## 何時使用

- 建置編輯部 SOP
- 選題會議(週會、月會)
- 個別記者稿單管理
- 多稿並行之 deadline 追蹤
- 編輯與記者交接
- 新進記者訓練

---

## 一、選題追蹤(週/月選題會議)

### 選題分類矩陣

| 類別 | 例子 | 時效 |
|---|---|---|
| **時效 (Spot)** | 突發新聞、即時事件 | 當日 |
| **延伸 (Reaction)** | 對時效事件之追蹤、評論、背景 | 1-3 天 |
| **深度 (Feature)** | 人物、議題分析、特稿 | 1-4 週 |
| **調查 (Investigation)** | 揭弊、政府監督、企業調查 | 1-6 個月 |
| **資料新聞 (Data)** | 統計分析、趨勢解讀 | 1-3 週 |
| **服務 (Service)** | 教戰守則、生活資訊 | 不限 |
| **意見 (Opinion)** | 社論、評論、專欄 | 視議題 |

### 選題優先級

| 優先級 | 標準 |
|---|---|
| **A 級** | 獨家 + 公益高 + 時效強;**砸資源做** |
| **B 級** | 公益高但非獨家 / 時效強但非獨家;**穩定產出** |
| **C 級** | 軟性、生活、補充內容;**填版面** |
| **D 級** | PR 稿轉化、編譯外電;**避免成為主流** |

### 選題會議模板

```markdown
## 編輯部選題會議:2026 年 ○ 月 ○ 日

### 上週稿單檢討
- 完成:[列]
- 延後:[列] + 原因
- 未刊:[列] + 原因

### 本週時效議題
1. [議題] - 負責人 - 預定發稿日
2. ...

### 本週深度議題
1. [議題] - 負責人 - 預定發稿日 - 採訪進度
2. ...

### 進行中之調查
1. [議題] - 負責人 - 已進行 ○ 週 - 下一步
2. ...

### 跨組合作議題
1. [議題] - [組 A + 組 B] - 分工
2. ...

### 未來 3 個月之季線議題
- [議題]
- ...

### 待議
- 是否要追某個外媒議題?
- 是否要做某個專題?
- 人力分配調整?
```

## 二、稿單管理

### 單筆稿件追蹤模板

```markdown
## 稿件 #YYYY-MM-DD-NNN

**標題**:[暫定標題]
**作者**:[記者]
**編輯**:[負責編輯]
**類別**:[時效/深度/調查/資料/意見]
**優先級**:[A/B/C/D]
**字數預估**:[字]
**預定發稿日**:[日期]
**進度**:[採訪中 / 撰稿中 / 編輯中 / 待發 / 已發]

### 進度紀錄
- YYYY-MM-DD:選題會議通過
- YYYY-MM-DD:採訪 [對象],紀錄 [連結]
- YYYY-MM-DD:撰稿初稿,字數 [],檔案 [連結]
- YYYY-MM-DD:編輯修改 第一輪 [連結]
- YYYY-MM-DD:法務審查(若有)
- YYYY-MM-DD:發稿

### 風險與顧慮
- [ ] 法律風險(妨害名譽、個資)
- [ ] 政治敏感
- [ ] 廣告主關係
- [ ] 倫理疑慮(受害者、未成年人)
- [ ] 與其他媒體競爭時間
- [ ] 撤稿風險

### 待辦
- [ ] 求證 X 機關
- [ ] 補拍照片
- [ ] 圖表設計
- [ ] 校對
- [ ] 法務簽核(若需要)
```

## 三、編輯部分工

### 一般中型編輯部架構

```
總編輯 (Editor-in-Chief)
  ├── 副總編輯 (Deputy Editor)
  │     ├── 政治組 (Politics)
  │     ├── 社會組 (Social Affairs)
  │     ├── 經濟組 (Business)
  │     ├── 國際組 (International)
  │     ├── 體育文化組 (Sports & Culture)
  │     └── 地方組 (Local) — 各分社
  ├── 執行編輯 (Executive Editor) — 每日版面、發稿節奏
  ├── 校對組 / 編務組
  ├── 法務 / 倫理委員會
  ├── 攝影組
  ├── 視覺 / 互動 / 資料組
  ├── 影音組
  ├── 社群編輯 (Social Media Editor)
  └── 數位營運 (Digital Operations)
```

### 紙本 vs 數位 vs 廣電不同

| 媒體類型 | 編輯部特點 |
|---|---|
| **紙本日報** | 截稿時間明確、版面有限、可校對較久 |
| **網路新聞** | 24/7、即時更新、SEO、社群推播 |
| **週刊** | 深度為主、週循環、影像比重高 |
| **廣電** | NCC 規範嚴、文字精簡、配音、剪輯 |
| **獨立記者 / 自媒體** | 一人多工、無分工奢侈、跨領域 |

## 四、發稿前審核流程

### 三層審核(理想)

```
[1. 自審 (記者)]
   ├── 5W1H 完整
   ├── 引語對照逐字稿
   ├── 數字、姓名、職稱核對
   ├── 觸發 ai-writing-detox-tw 自我檢查
   ├── 觸發 newsroom-style-tw 編務規範
   └── 觸發 fact-check-workflow-tw 主張查核
        ↓
[2. 編輯審 (編輯)]
   ├── 結構、敘事流暢
   ├── 標題、副標
   ├── 圖文搭配
   ├── 平衡性(各方意見併陳)
   └── 公平、客觀
        ↓
[3. 終審 (執行編輯 / 副總編)]
   ├── 法律風險
   ├── 政治敏感
   ├── 倫理判斷
   ├── 整版搭配
   └── 簽發
```

### 風險議題之特別審核

| 議題類型 | 加審 |
|---|---|
| 涉訴訟、被告 | 法務 |
| 兒少、性平受害者 | 倫理委員會 |
| 醫療、健康主張 | 醫療顧問或衛福部澄清 |
| 軍事、外交、兩岸 | 國安、外事顧問 |
| 重大商業爭議 | 法務、廣告部協調 |
| 政治選舉期 | 政治組主管簽核 |

## 五、編輯與記者交接

### 採訪指派模板

```markdown
## 採訪指派單

**指派日期**:YYYY-MM-DD
**指派人 (編輯)**:[姓名]
**承接人 (記者)**:[姓名]

### 採訪主題
[一句話]

### 採訪目的
- [ ] 寫成何種形式之稿件 (時效 / 深度 / 調查)
- [ ] 字數預估
- [ ] 預定發稿日

### 必訪對象
1. [人 / 機構]
2. ...

### 必查資料
- [ ] 公開資料 X
- [ ] 政資法申請(若需)
- [ ] 司法院判決
- [ ] ...

### 已知背景
[編輯掌握之背景、相關報導連結]

### 角度提示
[編輯希望切入之角度,但不限制記者自由探索]

### 風險評估
[政治、法律、倫理之顧慮]

### 預算 / 資源
- 出差?
- 拍照、影像?
- 法務?
- 跨組合作?
```

### 編輯改稿準則

| 改稿項目 | 原則 |
|---|---|
| **事實錯誤** | 記者必須同意之具體事實 |
| **結構調整** | 與記者討論,不強行 |
| **語感、風格** | 編輯有最終決定權,但需與記者協商 |
| **標題** | 編輯部最終決定,但需告知記者 |
| **刪節** | 與記者討論;若大幅刪節須告知原因 |
| **加入未經採訪之內容** | **絕不允許**(編輯不可代記者寫採訪內容) |

## 六、新進記者訓練

### 入職一個月 checklist

```markdown
- [ ] 媒體歷史、定位、編輯方針
- [ ] 報導倫理、公約
- [ ] 內部編輯部規範(用字典範、政治用語立場)
- [ ] 採訪設備使用(錄音、攝影、轉檔)
- [ ] 主要採訪路線、聯絡人
- [ ] 重大新聞 SOP(突發、災害、選舉)
- [ ] 法律基礎(誹謗、個資、政資法、社維法)
- [ ] 公開資料庫操作(政資法、判決庫、公開觀測站)
- [ ] 編輯流程(投稿、修稿、終審)
- [ ] 跨組合作流程
- [ ] 設備、辦公室、出差規範
- [ ] 緊急聯絡名單
```

### 跟隨資深記者(2-4 週)

- 採訪同行
- 寫稿配對(雙作者)
- 編輯部會議旁聽
- 議題討論練習

## 與其他 -tw skill 協作

`editorial-workflow-tw` 處理**編輯部之流程管理**。其他 skill 處理**單篇稿件之內容工作**:

```
[編輯部流程]            ← editorial-workflow-tw (你在這裡)
   ├── 選題決策
   ├── 資源分配
   ├── 進度追蹤
   └── 發稿前審核
        ↓
[單篇稿件之工作流]
   ├── foia-requests-tw       資料蒐集
   ├── source-verification-tw 來源驗證
   ├── social-media-intelligence-tw OSINT
   ├── interview-prep-tw      採訪
   ├── fact-check-workflow-tw 查核
   ├── ai-writing-detox-tw    去 AI 味
   ├── newsroom-style-tw      編務規範
   └── crisis-communications-tw 突發新聞應變
```

### 重疊處理

- **發稿前 checklist**:
  - `editorial-workflow-tw` §四:三層審核流程(自審/編審/終審)
  - 各 -tw skill 末尾的「發稿前 checklist」是**自審層**
  - 編輯部審核應涵蓋自審 + 結構 + 風險

- **新進記者訓練**:
  - `editorial-workflow-tw` §六:入職 checklist
  - 詳細內容散見其他 -tw skill(法律、查核、編務等)
  - editorial-workflow-tw 是**入口**,引導讀相關 skill
