# 台灣新聞採訪準備工作流程

採訪**失敗在準備,不在對話**。本 skill 涵蓋台灣場景的訪前研究、問題設計、錄音法律、訪後追蹤。

---

## 何時使用

- 準備採訪某位來源前
- 為定期訪談類型設計問題框架
- 處理採訪邏輯與同意
- 規劃首次採訪後的追蹤
- 訓練新進記者之訪談技巧
- 處理錄音相關法律爭議

## 一、採訪前研究 checklist

### 背景研究(台灣公開資料)

```markdown
## 受訪者背景查證(台灣場景)

### 公開記錄
- [ ] 專業執照(衛福部醫事人員執業登記、律師公會、會計師公會、建築師公會)
- [ ] 法院判決(司法院法學資料檢索 judgment.judicial.gov.tw)
- [ ] 公司登記(經濟部商業司 gcis.nat.gov.tw)
- [ ] 上市櫃公司資訊(公開資訊觀測站 mops.twse.com.tw)
- [ ] 不動產登記(地政司線上查詢)
- [ ] 政治獻金 / 競選財務(中選會、廉政署)
- [ ] 公職人員財產申報(廉政署 ace.moj.gov.tw)
- [ ] 政府電子採購網(若為承包廠商)

### 專業背景
- [ ] LinkedIn 已檢視
- [ ] 雇主已確認
- [ ] 前雇主已聯絡(若關鍵)
- [ ] 發表作品已檢視
  - 學術:Google Scholar、台灣博碩士論文知識加值系統 ndltd.ncl.edu.tw
  - 媒體:過往受訪、專欄
- [ ] 研討會、公開演講出席紀錄

### 社群媒體稽核
- [ ] 所有平台已識別(Threads / FB / X / IG / LinkedIn / Threads / Dcard / PTT 等)
- [ ] 發文歷史已檢視
- [ ] 對該議題之既有發言
- [ ] 是否有已刪除內容?(用 Wayback / Archive.today 找)

### 媒體露出
- [ ] 過往受訪已找出
- [ ] 與當前主張一致性
- [ ] 其他記者之評估
- [ ] 是否有撤回或更正?
```

> **詳細的台灣公開資料庫清單請參考 `source-verification-tw` §十一**(訪談前公開資料查證有完整 12 項對照表)。

### 主題脈絡研究

```markdown
## 主題準備

### 核心知識
- [ ] 主題之關鍵事實已確認
- [ ] 事件時序已建立
- [ ] 其他利害關係人已識別
- [ ] 衝突敘事已記錄
- [ ] 相關文件/數據已檢視

### 撥電話前該知道
- [ ] 該受訪者在故事中的位置?
- [ ] 我**最需要**從這場訪談得到什麼?
- [ ] 他可能不願談的議題?
- [ ] 他過去公開說過什麼?
```

## 二、問題框架(國際通用)

### 5 個必問

每場訪談應該回答:
1. **發生了什麼?**(事實)
2. **為什麼發生?**(原因)
3. **你做了/決定了/看到什麼?**(行動)
4. **這意味著什麼?**(意義)
5. **接下來呢?**(影響)

### 6 種問句類型

| 類型 | 目的 | 範例 |
|---|---|---|
| **開放式** | 取得完整故事 | 「跟我說那天到底發生了什麼。」 |
| **釐清式** | 確認細節 | 「你說『不久之後』,是幾分鐘還是幾小時?」 |
| **追問式** | 深入挖掘 | 「為什麼你覺得這件事會發生?」 |
| **追蹤式** | 抓矛盾 | 「你剛才說 X,但現在提到 Y,可以幫我釐清嗎?」 |
| **對質式** | 質疑陳述 | 「文件顯示 [事實],請問你怎麼回應?」 |
| **收尾式** | 確保完整 | 「我有沒有沒問到、但你覺得我該知道的?」 |

### 訪談類型模板

**人物特寫**:
```
1. 背景:「跟我說你的成長過程 / 怎麼開始投入這行?」
2. 轉折點:「你什麼時候意識到 [X] 是你的路?」
3. 挑戰:「在 [某段時期] 最難的時刻是什麼?」
4. 價值觀:「指引你工作的核心原則是什麼?」
5. 未來:「你接下來在做什麼?」
```

**調查報導**:
```
1. 建立信任:從非敏感的背景問題開始
2. 時序:「跟我從頭講一遍 [事件]。」
3. 細節:「還有誰在場?你看到/聽到什麼?」
4. 文件:「你有任何相關紀錄嗎?」
5. 旁證:「還有誰可以證實這件事?」
6. 回應:「[另一方] 知道你舉發這件事時,怎麼回應?」
```

**專家/解釋者**:
```
1. 資歷:「你在這領域的專長是?」
2. 平實語言:「請把 [概念] 解釋給非專家聽。」
3. 脈絡:「[這個情況] 有多常見/多特殊?」
4. 重要性:「為什麼這件事重要?」
5. 來源:「我還能在哪裡學更多?還有誰我該訪?」
```

**敏感議題 / 受害者**:
```
1. 控制感:「不急,你隨時可以停。」
2. 開放:「你願意分享的部分就好。」
3. 具體:「你能描述 [特定細節] 嗎?」
4. 衝擊:「這件事對你有什麼影響?」
5. 主體性:「你最想讓大家了解什麼?」
6. 檢查:「你還好嗎?可以繼續嗎?」
```

## 三、錄音與同意(台灣法律框架)

> **核心法源**:《刑法》§315-1 妨害秘密罪 + 《通訊保障及監察法》§29 第 3 款。

### 《刑法》第 315-1 條(2026 年 5 月版本)

「**有下列行為之一者,處 3 年以下有期徒刑、拘役或 30 萬元以下罰金**:

一、無故利用工具或設備窺視、竊聽他人非公開之活動、言論、談話或身體隱私部位者。

二、**無故以錄音、照相、錄影或電磁紀錄竊錄他人非公開之活動、言論、談話或身體隱私部位者**。」

**重點**:
- 「**無故**」是構成要件 — 有「**法律上正當理由**」即不算「無故」
- 「**他人**」是構成要件 — 記者**自己為對話之一方**時,所錄非「他人」之談話

### 《通訊保障及監察法》第 29 條第 3 款

「監察他人之通訊,而有下列情形之一者,**不罰**:

三、**監察者為通訊之一方或已得通訊之一方事先同意,而非出於不法目的**。」

### 實務判決見解(2026 年 5 月概況)

| 判決方向 | 案例 | 要旨 |
|---|---|---|
| **記者錄音通常合法** | 台北地院 108 年度自字第 51 號 | 對話一方為保護自身權益錄音,**非無故錄音,不構成妨害秘密罪** |
| **但「非公開」與「非對話一方」要小心** | 高雄高分院 109 年度上訴字第 1408 號 | 被告在非公開調解程序中,**未經他人同意**錄音,構成妨害秘密 |

### 記者實務原則(Taiwan one-party consent 框架)

**法律允許但仍建議**:

| 情境 | 法律狀態 | 倫理建議 |
|---|---|---|
| 我是對話之一方(電話、面對面)+ 錄音 | ✅ **合法**(§29-III 一方同意) | **告知對方錄音** — 建立信任、避免日後爭議 |
| 我是對話之一方 + 偷錄(對方不知) | ✅ 多數判決認為**合法** | **慎用**;新聞倫理上有爭議,僅在「公益重大且無其他方式」時考慮 |
| 我不是對話一方 + 偷錄(竊聽他人) | ❌ **觸法**(§315-1) | 絕不可以,即使為了新聞 |
| 在私人住宅、醫院病房、學校教室等隱私場所錄音 | ⚠️ 高度爭議,**多數判決傾向構成「非公開活動」** | 進入該空間前必須**書面同意** |
| 公開記者會、立法院質詢、法院公開審理 | ✅ 公開活動,非「他人非公開談話」 | 一般無需特別同意,但仍**告知**較佳 |

### 錄音 SOP(每次訪談一定要做)

1. **開始前明確告知**:
   ```
   「○○○先生(女士),我是[媒體]記者[姓名],這場訪談我會
   錄音作為新聞使用,請問可以嗎?」
   ```
2. **取得明確回應**(口頭「可以」「我同意」均可)
3. **錄音檔本身錄下同意過程**(法律上最有力的證據)
4. **筆記中文件化**:時間、地點、同意方式
5. **若對方拒絕**:停止錄音,改用筆記;**詢問是否可改為「事後傳訊息確認 quotes」**

### 同意紀錄模板

```markdown
## 錄音同意紀錄

日期:[YYYY 年 MM 月 DD 日]
記者:[姓名]
媒體:[本社]
受訪者:[姓名]
媒介:[電話 / 視訊 / 親訪]
地點:[若親訪]

[錄音開頭明確發言]:
「這是 [媒體記者姓名],今天 [日期] 訪談 [受訪者姓名]。
我會錄音作為新聞使用,並可能引用於發稿。請問可以嗎?」

[對方回應]:
□ 同意:是 / 否
□ 同意公開使用:是 / 否
□ 同意具名:是 / 否
□ 同意錄影(若有):是 / 否

備註:[特殊約定,例如「××段不上稿」「××部分匿名」]
```

### 不可錄音的場合

即使你是對話一方,下列場合**仍應特別小心**或避免錄音:

- **隱匿身分採訪**(臥底、假裝路人)— 倫理與法律雙重高風險
- **進入私人住宅未經邀請**
- **醫院病房、加護病房**
- **學校未公開的師生對話**
- **未成年人**(需法定代理人同意)
- **法院非公開審理庭、調解庭**
- **教會、寺廟之非公開宗教活動**

> **更詳細的法律框架請參考 `source-verification-tw` §十二**(法律風險章節)與 `fact-check-workflow-tw` §九。

## 四、歸屬規則(台灣媒體實務)

### 4 種歸屬等級

| 等級 | 含義 | 使用時機 |
|---|---|---|
| **具名(on the record)** | 全名 + 職稱皆可發布 | 預設;除非另約定 |
| **不具名背景(on background)** | 資訊可用,但**不具名** | 對方有顧慮但仍願提供 |
| **深背景(deep background)** | 資訊**指引採訪**,不可引用、不可作為證據 | 需另尋管道驗證 |
| **不可發布(off the record)** | **僅供你個人理解**,不可發布、不可用以查證 | 罕用;**事前**同意才有效 |

### 台灣媒體常用之「不具名」描述

- **「不具名官員指出」** — 部會層級內部人士
- **「知情人士透露」** — 廣泛範圍,**新聞倫理批評最強**
- **「該案承辦人(因案件性質不便具名)指出」** — 具體說明匿名理由
- **「○○部資深官員表示」** — 帶資歷標籤
- **「業界人士」/「業內人士」** — 商業議題
- **「黨內人士」/「綠營/藍營人士」** — 政治議題
- **「警方消息來源」** — 警方相關

> **詳見 `newsroom-style-tw` §八「消息來源的標示」**:具名規範、不具名來源等級、避免使用「據了解」。

### 釐清歸屬之話術(訪前)

```
訪前明確問:
「進入採訪前先確認一下,我們是『on the record』(可以具名引用)
嗎?如果你有任何顧慮,我們可以討論。」

若對方要求不具名:
「我比較希望具名。可以告訴我你的顧慮嗎?」

若對方堅持:
「好,那我們改成 background。我可以怎麼稱呼你?『○○部不具名
官員』可以嗎?」

文件化:
「所以我可以稱你為 [約定稱謂],對嗎?」
```

### 「事後反悔」處理

| 情境 | 處理 |
|---|---|
| 對方說完後突然要求「剛才那段不要寫」 | 「我們開始前已經約定是 on the record。若要改,我們可以討論,但我無法承諾。」 |
| 對方說完才說「那是 off the record」 | **可以拒絕** — off the record 必須**事前**同意才有效 |
| 對方說完後要求修改 quote | 可以**事實性修正**(數字、日期錯誤);**不接受改變語意**之修改 |
| 對方說完後要求**整段不上稿** | 評估公益必要性;若是政治人物對重大公益議題之發言,可不接受 |

## 五、採訪邏輯與後勤

### 採訪邀約模板(電子郵件)

```
主旨:採訪邀約 - [主題] - [本社]

[受訪者姓名] 先生 / 女士:

您好。我是[本社]記者[姓名](通訊:[電話 / email])。我目前正在
撰寫一則關於 [主題之簡短誠實描述] 的報導,希望能採訪您。

[記者姓名]

[聯絡資訊]
```

## 六、採訪中

### 開場
- **適度的閒聊**建立信任(不超過 2-3 分鐘)
- 確認對方可用時間
- 明確說明錄音並取得同意
- 從**簡單、開放的問題**開始

### 主動傾聽
- 讓對方說完句子,**不要打斷**
- **善用沈默** — 不要急著填補每一個空檔(這通常是受訪者最有訊息的時刻)
- 即使錄音也記筆記
- **非語言線索**(肢體、表情)另記

### 即時驗證
- 詢問具體細節:日期、姓名、地點
- 訪談中索取文件
- 「你怎麼知道的?」
- 記下不一致之處備追蹤

### 收尾
- 「我有沒有沒問到、但你覺得我該知道的?」
- 「我還該訪誰?」
- 「我有後續問題可以再聯絡你嗎?」
- 感謝對方撥冗

## 七、追蹤 protocol

> 錄音備份、轉錄工具、引語驗證之機制請參考 `interview-transcription-tw`(本 plugin 將來在地化項目)。本節聚焦**訪後編輯流程**。

### 即時(當日)
- [ ] 備份錄音(雲端 + 本機,**至少兩份**)
- [ ] 記下未錄到的觀察(肢體、環境、結束後對話)
- [ ] 如適合,寄感謝信

### 48 小時內
- [ ] 對主張與既有紀錄交叉查核(觸發 `fact-check-workflow-tw`)
- [ ] 識別需追蹤的缺口
- [ ] 將來源加入聯絡資料庫

### 發稿前
- [ ] 引語準確性已驗證(對照錄音/逐字稿)
- [ ] 歸屬條件已確認
- [ ] 若承諾「回讀引語」,執行
- [ ] 對有新聞性的描述,給對方回應機會

## 八、困難情境應對

### 訪談中突然要 off the record

```
「在我同意之前,先讓我聽你想說什麼,然後我們再討論怎麼處理。」
```

### 拒絕回答

```
「我了解你不能討論這個。可以指給我能談的人嗎?」
```

### 充滿敵意

保持冷靜,問句改為**事實性**而非質疑性:
```
「我只是想了解到底發生了什麼。」
```

### 哭泣 / 情緒崩潰

暫停。
```
「不急,你隨時可以停。」
「我們可以休息一下。」
```

### 受訪者說謊

**不要當場指控**;以反證提示:
```
「文件顯示 [X]。你能幫我釐清這個落差嗎?」
```

### 政治人物迴避

政治人物常以「我不便評論」「這是黨團決定」「我已經回應過」迴避:
```
「我了解這是黨團立場。但作為這個選區的立委,你個人對此的看法是?」
「你之前在 [日期 / 場合] 說過 [X]。是否仍如此認為?」
```

### 公關擋下問題

PR 公關常代發言。**直接面對當事人**:
```
「謝謝公關協助。但我想直接請教 ○○ 先生本人對這個議題的看法。」
```

### 拒絕指認某個具體人

```
「我了解你不願具名。我們可以用『○○部資深官員』這樣描述嗎?」
```

## 九、台灣特殊受訪對象

### 政治人物(立委、議員、政務官、地方首長)

**特性**:
- 採訪時間極短(發稿前 5-10 分鐘攔截)
- **公開回應**多有 PR 把關
- **私下回應**可能與公開不一致
- 引用前**回讀**是常見要求(必要時拒絕)

**準備重點**:
- 看過其**過去質詢、政見、投票紀錄**(立法院議事公報、地方議會議事錄)
- 看過其**社群發言**(FB、Threads、Line 群組擷取)
- 預備**3-5 個重點問題**,順序排好

**禁忌**:
- 不要在「便利商店問早安式」採訪中問複雜政策(問也問不到答案)
- 不要被 PR 引導改變題綱
- 不要承諾「全文發布逐字稿」(除非編輯部同意)

### 政務官 / 高階公務員

**特性**:
- **保守、字斟句酌**
- 引用前要求「校稿」極為常見
- 涉及機密議題時會以「業務考量」迴避
- 訪後可能透過公關處再「補充說明」

**準備重點**:
- 對其**機關職掌**有清楚認識
- 對相關**法規條號**已查證
- 預備**具體案例**而非抽象問題
- 涉及具體決策時,**準備「政資法申請書」備案**(若不願口頭說明,你可以申請相關文件)

### 原住民族長老 / 部落 議題

**特性**:
- **長者口述歷史傳統**(可能慢、回憶式、需耐心)
- **部落集體決策**(個人發言可能需先取得部落會議同意)
- 涉及**族語**時,可能需翻譯

**準備重點**:
- 對該族**基本概念**有認識(原住民族委員會官網 cip.gov.tw)
- 學該族**基本問候語**(尊重)
- **避免「番」「山地」「土著」等歧視用詞**(詳見 `newsroom-style-tw` §十)
- 與**部落協會、部落會議**事前溝通
- 涉及**祖傳故事、歌謠**可能涉及智慧財產權(《原住民族傳統智慧創作保護條例》)

### 移工 / 外籍工作者

**特性**:
- **語言隔閡**(可能需越南、印尼、菲律賓、泰語譯者)
- **法律處境脆弱**(逃逸移工、合約糾紛、雇主威脅)
- 引述可能影響其**居留權**

**準備重點**:
- **絕對匿名**:不要將真名、地點、雇主名稱寫在訪談筆記中
- 透過**移工工會或 NGO** 安排(台灣國際勞工協會 TIWA、桃園市群眾服務協會等)
- 詢問是否同意**不刊出照片**(深度報導常見要求)
- 訪後**確認回讀**:其聲音是否準確傳達

### 性平議題受害者(性騷擾、性侵、性別暴力)

**特性**:
- **二次創傷風險高**
- 需要**控制感**(可暫停、可拒絕回答、可改變主意)
- **保密原則**極為關鍵
- 引述可能引發**反擊**

**準備重點**:
- 訪前看過受害者保護準則(現代婦女基金會、勵馨基金會、台灣性別人權協會)
- **詢問偏好性別**(同性別記者)
- **不問細節**,讓對方主導敘述
- **書面同意**(可撤回);明確告知後續對方權利
- 提供**心理諮商資源連絡方式**(衛福部保護專線 113;勵馨 02-2369-3700)
- **報導前再次確認**:對方仍同意公開

### 災難受害者 / 倖存者 / 罹難者家屬

**特性**:
- **時間敏感**:災後黃金 72 小時內 vs. 災後 6 個月
- **情緒高峰**或**麻木期**
- **記憶不一致**(創傷反應)

**準備重點**:
- **避免「請描述當下感受」**(刺激式問句)
- **以事實為主、感受為輔**
- 同行的攝影/錄影應**克制鏡頭**
- 詢問是否願**匿名**;若願具名,**確認家屬同意**

### 兒少受訪者

**法律基礎**:依《兒童及少年福利與權益保障法》§69 等規定,涉兒少之新聞報導**不得揭露其身分**。

**特性**:
- **未成年**需法定代理人同意
- 校園議題敏感
- 報導不可揭露真名、學校、班級、影像清晰可辨

**準備重點**:
- 先取得**法定代理人**(父母、監護人)書面同意
- 涉**重大公益議題**(校園霸凌、教師性騷擾)時與校方、家長三方溝通
- **保護原則優於新聞性**:即使家長同意,仍應評估對兒少之長期影響

### 加害人 / 嫌疑人 / 被告

**特性**:
- 涉**訴訟、偵查中**案件,**回應有法律考量**
- 律師可能在場
- 引述可能被**用於訴訟**

**準備重點**:
- 預備明確採訪邀約信(註明日期、主題、可發布條件)
- 對方律師若要求**書面採訪**,可考慮(回應時間較充裕)
- 涉**偵查不公開**之原則,避免在訴前報導前引用偵查中資料
- 引述其回應時務必**精準**,避免被告主張媒體斷章取義

## 十、與其他 -tw skill 協作

`interview-prep-tw` 處理**人對人採訪之程序**。實務中與其他 -tw skill 緊密協作。

### 典型記者工作流順序(6 個 skill 串接)

```
[1. 資料蒐集]                  ← foia-requests-tw
       ↓
[2. 來源驗證 / 內容查證]       ← source-verification-tw
       ↓
[3. 採訪準備 / 採訪]           ← interview-prep-tw  ← 你在這裡
       ↓
[4. 主張驗證 / 查核]           ← fact-check-workflow-tw
       ↓
[5. AI 起草草稿]
       ↓
[6. 去 AI 寫作味]              ← ai-writing-detox-tw
       ↓
[7. 編務校對]                  ← newsroom-style-tw
       ↓
[8. 發稿]
```

> `interview-prep-tw` 在工作流中可**接在 source-verification-tw 之後**(訪前驗證受訪者背景)、**亦可在 fact-check-workflow-tw 之前**(訪後將引語送查核)。

### `interview-prep-tw` 結束後,何時觸發其他 skill

| 場景 | 轉手 skill | 章節 |
|---|---|---|
| 訪前需查證受訪者公開資料 | `source-verification-tw` | §十一訪談前公開資料查證 |
| 訪前需取得機關文件(政資法申請) | `foia-requests-tw` | §10 應載事項 + §22 工本費減免 |
| 訪後將引語送查核 | `fact-check-workflow-tw` | §二主張提取、§三~五查證與評等 |
| 訪後處理錄音轉逐字稿 | `interview-transcription-tw`(本 plugin 將來在地化) | — |
| 撰稿前去除訪談稿之 AI 味與口語冗詞 | `ai-writing-detox-tw` | §三句型套語、§六新聞文體 |
| 引述格式、不具名來源規範、引述動詞 | `newsroom-style-tw` | §八引述動詞、§四職稱 |
| 涉妨害名譽風險 | `fact-check-workflow-tw` + 法務 | §九法律風險 |

### 重疊處理

- **錄音法律**:
  - `interview-prep-tw` §三:**主處理**(《刑法》§315-1、《通保法》§29 第 3 款、SOP)
  - `source-verification-tw` §十二:簡要提及
  - **以 `interview-prep-tw` §三為準**

- **訪談前公開資料**:
  - `source-verification-tw` §十一:**主處理**(12 個公開資料庫詳細清單)
  - `interview-prep-tw` §一:概要(指向前者)
  - **以 `source-verification-tw` §十一為準**

- **引述動詞色彩**:
  - `newsroom-style-tw` §八:**主處理**(20+ 個動詞色彩表)
  - `interview-prep-tw`:不另列
  - **以 `newsroom-style-tw` §八為準**

- **不具名來源**:
  - `interview-prep-tw` §四 + §八:採訪程序與話術
  - `newsroom-style-tw` §八:寫稿時匿名規則
  - `fact-check-workflow-tw` §三 + §四:證據強度評估
  - `source-verification-tw`(若爆料者身分需驗證)
  - **四 skill 搭配最完整**

- **特殊受訪對象**:
  - `interview-prep-tw` §九:**完整處理**(8 種特殊對象)
  - **獨家內容**,其他 skill 無對應

### 建議搭配安裝

`interview-prep-tw` 可獨立用作「**台灣採訪準備手冊**」(學生實習、新進記者訓練皆適用)。**新聞工作者建議同時安裝至少** `source-verification-tw`(訪前公開資料)、`fact-check-workflow-tw`(訪後查核)、`newsroom-style-tw`(發稿格式)。
